# pNet Plex

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [简体中文](README.zh-CN.md)

**Соберите команду. Координируйте работу.**

Plex — **agent harness для оркестрации и координации нескольких агентов** в
OpenAI Codex, Anthropic Claude Code и Google Antigravity. Установите готовую команду,
выберите профиль моделей и поручите Plex организовать реализацию, ревью и проверку.

**[v0.4.0 Preview](https://github.com/pnetcloud/plex-ai/releases/tag/v0.4.0)** — открытый проект, MIT. Можно пробовать; интерфейсы ещё могут меняться.

## Быстрый старт

Нужны **Git и curl**, CLI выбранного клиента и **uv или Python 3.11+**. Запускайте из папки
своего проекта или создайте пустой проект для знакомства:

```sh
mkdir plex-demo && cd plex-demo
```

Установите прямо из GitHub одной командой:

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Установщик откроет интерактивное меню:

1. Выберите клиентов **пробелом**, затем нажмите **Enter** (без uv — вводом номеров).
2. Для этого теста оставьте область **Project** и подтвердите папку проекта.
3. Выберите самостоятельную команду **pnet** и профиль **Inherit**, чтобы использовать настройки моделей сессии.
4. Проверьте и подтвердите план установки для каждого клиента.

Установятся общий плагин, нативные роли команды и управляемый блок инструкций.
Для обновления и повторной настройки запустите ту же команду.

## Попробуйте первую задачу

Откройте **новую сессию** своего клиента в `plex-demo` или вашем проекте.
При необходимости перезагрузите плагины/агентов и отправьте:

```text
Используй Plex, чтобы сделать адаптивную страницу записи на фокус-сессию.
Чистые HTML, CSS и JavaScript: имя, email и длительность 25/50 минут.
Проверяй ввод и показывай локальное подтверждение без хранения и отправки данных.
Проведи ревью, выполни доступные проверки и укажи, что действительно проверено.
```

Plex выберет нужные роли, реализует страницу и организует ревью и проверки.
Ожидаемый результат: исходники, команда локального просмотра, отчёт о проверках и оставшихся пробелах.
Установка сама не запускает оркестрацию — **нужно явно попросить использовать Plex**.

Нашли проблему? [Создайте issue](https://github.com/pnetcloud/plex-ai/issues): клиент и версия,
команда и профиль, команда терминала или запрос, ожидаемое и фактическое поведение.
Перед приложением логов удалите секреты.

## Команды и модели

| Команда | Для чего |
|---|---|
| **pnet** | Обычная разработка: PM, explorer, researcher, dev, reviewer и QA; BMad не требуется |
| **bmad** | Скиллы и workflow BMad с моделями по ролям; установщик предлагает установку выбранных skills и инициализацию проекта |

Профили: **Inherit, Basic, Plus, Pro, Pro+**. Один уровень применяется ко всем выбранным
клиентам; доступны переопределения по ролям. Plex управляет только отмеченным блоком,
сохраняя окружающие инструкции проекта.

Для смены настроек или подключения другого проекта запустите **в терминале** из его папки:

```sh
~/.local/bin/plex
```

Эта команда открывает настройку, а запрос Plex внутри клиента запускает координацию.
Обновления, глобальная установка, флаги и переопределения — в [конфигурации](docs/translations/ru/configuration.md).

## Проверка, обновление и удаление

```sh
plex status
plex update
plex uninstall --dry-run
```

Для удаления запустите `plex uninstall` и подтвердите план. Если `plex` нет в PATH, используйте `~/.local/bin/plex`.
Установка и обновления выбирают опубликованные релизы, включая preview.

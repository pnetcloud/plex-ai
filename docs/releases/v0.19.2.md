# Plex AI v0.19.2

Plex coordinators now check progress toward observable acceptance milestones instead of relying on repeated status messages.

- When successive reports show no new evidence for the same milestone, inspect the referenced artifact or check. Ask the same executor for missing details only when needed, and reuse its answer on unchanged polls.
- Let advancing implementation continue without repeated status requests, Build restarts or extra manager cycles. Component checks remain partial evidence, not proof of completed integration.
- Reconcile checkpoint owners, blockers and next actions with current accepted assignments. Preserve completed work, required specialist decisions, human approvals and workflow checks.
- Back off unchanged waits within host limits. No execution timer, token budget, model change or new contract schema is introduced.

Run `plex update`, preserving your team/profile. Start a new session to load the new instructions, or explicitly pass the relevant rule changes to the existing coordinator and reused executors. Updating files alone does not change a running agent's initial instructions. Do not restart completed work just to adopt this patch.

Verification: the full local test suite and shell checks passed, including contract, checkpoint, documentation and package checks. Scenario review covers stale checkpoints, repeated statuses and legitimately advancing work. This is prompt guidance, not a deterministic loop detector; live improvement remains to be observed.

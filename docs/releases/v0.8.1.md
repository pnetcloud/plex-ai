# Plex AI v0.8.1

Codex roles inherit permissions from the main chat.

- Generated role TOML omits `sandbox_mode` and `approval_policy`. Configure permissions
  and MCP servers in the parent session.
- Read-only role instructions remain behavioral boundaries; they do not create a
  separate sandbox. Claude Code and Antigravity tool restrictions are unchanged.
- Refresh removes the old sandbox field from unchanged managed roles, with backups.
  Local role edits still trigger a conflict instead of being overwritten.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Refresh the team setup and open a new client session to load the updated roles.

# Plex AI v0.12.3

Coordinator recommendations now follow the same revised ladder in both `pnet` and BMad across all four provider recipes.

Plus recommends high reasoning, Pro xhigh, Pro+ max and Ultra low. Basic and Ultra+ remain unchanged. OpenAI uses Luna through Pro+ and Sol for Ultra/Ultra+; Claude Code uses Haiku then Sonnet. Native Google uses Flash through Pro+ and inherits the main-chat model for Ultra tiers. Claude on Antigravity retains its Sonnet substitutes and exact requested model IDs.

Subagent model and reasoning settings, profile IDs and interaction modes are unchanged. These are main-chat recommendations only: setup does not switch your running model. Update Plex to see the new recommendations, then choose the main-chat model in your client. Configuration and CI checks do not prove live model routing, equivalent quality or cost savings.

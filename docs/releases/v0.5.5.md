# Plex v0.5.5

A regular release with Claude Code delegation fixes and a clearer getting-started guide.

- Select Claude roles through `subagent_type`; put task labels in `description` and handoffs. Omit `name` so labeling cannot accidentally request an Agent Teams teammate.
- Deny the native `Agent` tool for roles with `delegation = false`, including pnet's dev and QA roles. BMad retains conditional nested delegation.
- Add native Claude validation, isolated plugin installation and configuration checks for both teams, without model calls.
- Simplify READMEs, add abstract Claude chat examples, and explain team removal separately from shared plugin removal in all four languages.
- Publish this and future releases without the GitHub prerelease flag or Preview title. The version remains 0.x; interfaces can evolve before 1.0.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Run setup to refresh the plugin and managed roles, then open a new client session. Running sessions are not rewritten.

## Validation

139 local tests passed, including native Claude Code 2.1.306 manifest validation, plugin installation in an isolated configuration, and pnet/BMad apply/check. Publication requires Linux/macOS CI on Python 3.11/3.14. No fresh model tasks were run: these checks verify installation/configuration, not live delegation, model availability or quality.

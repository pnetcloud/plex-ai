# Plex v0.1.0 — Preview

[English](https://github.com/pnetcloud/plex-ai/blob/v0.1.0/docs/releases/v0.1.0.md) · [Русский](https://github.com/pnetcloud/plex-ai/blob/v0.1.0/docs/translations/ru/releases/v0.1.0.md) · [Deutsch](https://github.com/pnetcloud/plex-ai/blob/v0.1.0/docs/translations/de/releases/v0.1.0.md) · [简体中文](https://github.com/pnetcloud/plex-ai/blob/v0.1.0/docs/translations/zh-CN/releases/v0.1.0.md)

First public prerelease. Plex configures reusable teams and coordinates coding agents inside OpenAI Codex, Anthropic Claude Code and Google Antigravity.

## Included

- One checkout installer with multi-client selection, project/user scope and shared model tiers.
- `pnet` and `bmad` teams with native agent definitions, root coordinator instructions and team-specific profiles.
- Explicit `plex` coordination and managed instruction blocks that preserve surrounding project instructions.
- English documentation with Russian, German and Simplified Chinese translations.
- Consolidated testing methodology, token/cost measurements, coordination findings and qualitative quality assessment.
- MIT license and attribution for adapted third-party instructions.

## Installation

Clone or download the tagged source, then run `./setup.sh` from the extracted checkout. Keep the checkout/export available while the installed local marketplace refers to it. The chosen client's CLI must already be available. BMad workflows require separately installed BMad skills and project runtime.

## Validation and limits

The development suite passed 76 tests. The benchmark archive contains 15 distinct completed runs passing 12/12 browser checks, plus stopped/blocked attempts documented separately. Individual runs do not establish a general efficiency ranking.

Codex and selected Antigravity configurations have live task evidence. Native Claude Code live execution, normal Codex sandbox operation, pure plugin-only BMad execution and screen-reader delivery remain unverified. Workflow-owned reviewer models can differ from standalone role profiles.

This preview is intended for experimentation. Configuration, role contracts and installation behavior may change before 1.0.

# Plex AI v0.7.0

Manager-owned assignments and bounded execution toward verified results.

- PM/PO selects normal execution, planning first or goal-driven work, with one to five observable acceptance criteria. Root schedules assignments and integrates evidence.
- A compact JSON assignment template and read-only validator check role membership, inputs, scope, readiness and execution settings against the checked team snapshot. Existing issue/spec/story stores remain authoritative.
- Native Plan/Goal modes are optional. Without them, keep ordinary planning or bounded criteria-driven execution. Native Goal requests default to 50,000 tokens, without automatic renewal; unsupported accounting is reported as unenforced.
- Installed `bmad-build-auto` is available for one unattended iteration. Preserve its renderer, required subagents, review stages and terminal protocol; reuse accepted specifications without another planning pipeline.
- Reuse role handles and pass changed evidence. Count unfinished assignments separately from native thread slots; preserve exact artifact paths/revisions instead of substituting similarly named files.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Refresh setup and open a new client session to load updated role instructions and the workflow catalog. Team membership, model profiles and installer configuration interfaces are unchanged.

Verification: 174 local tests (173 passed, one skipped without Claude CLI); six offline Docker installation lifecycles across all clients and both scopes. Native pnet execution and an installed BMad Build Auto iteration completed, including four workflow review leaves. Live smoke runs used sandbox bypass because the test host could not initialize `bwrap`; native Goal activation, budget enforcement and automatic continuation were not exercised.

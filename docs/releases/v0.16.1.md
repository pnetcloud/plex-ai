# Plex AI v0.16.1

Plex now stores `applied.toml`, `resolved.toml` and `skill-aliases.toml` beside `preset.toml` in `.plex/`, making generated configuration easier to read.

- Setup automatically migrates the three legacy JSON files when configuration is applied. Settings, overrides and ownership records are preserved; originals go to verified backups, with rollback on failure.
- Read-only status and preview support legacy installations. Matching copies are consolidated; conflicting JSON/TOML files remain untouched. Concurrent changes and symlinks are protected.
- `plex status` shows the observed config format. Assignment validation accepts old and new snapshots; CLI `--json` output remains JSON.
- Coordinator memory is explicitly a continuation aid. The coordinator keeps using the full available session context, accepted requirements and user corrections; missing checkpoint details are not cancelled.

Run `plex update` and apply the configuration to migrate automatically. Generated files remain installer-managed; durable settings belong in `preset.toml`. New client sessions load refreshed role instructions; active sessions may retain earlier instructions.

Verification: 244 tests and clean Docker installation checks across Codex, Claude and Antigravity, in project and user scopes. Migration checks cover semantic preservation, repeat updates, legacy reads/uninstall, collisions, concurrent writes and rollback. Live model behavior was not evaluated.

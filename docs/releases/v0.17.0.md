# Plex AI v0.17.0

Plex-owned agent assignments and responses now use readable Markdown with fixed headings, fields and lists. Both teams use the same templates and validator.

- Preserve assignment identity, revision, role, readiness, execution choice and one to five verifiable acceptance criteria.
- Validate progress, decision requests, blockers and completed responses against the current assignment, including criterion evidence. Reject malformed lists, unknown contract sections and duplicate fields.
- Keep legacy JSON contracts readable, including mixed-format assignment/response checks. Existing work does not need to restart or rewrite historical files.
- Keep coordination routes and workflow-owned return formats unchanged. Native tool envelopes and their display remain client-owned; validator diagnostics remain JSON.

Run `plex update` and apply configuration to refresh role instructions. Open a new client session to load the updated instructions. Historical contracts are not automatically rewritten.

Verification: 250 tests passed locally, covering Markdown templates, all response statuses, invalid inputs, multiline/Unicode content, legacy compatibility, read-only CLI behavior and package exports for all three clients. Live agent behavior and chat rendering were not evaluated.

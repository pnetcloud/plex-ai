# Plex AI v0.17.1

`plex update` now shows the current source version and selected target before downloading, for example `Plex update: v0.17.0 → v0.17.1`.

- Preview shows the same version transition without changing files.
- First installs show `not installed`; unreadable current version metadata shows `unknown` without blocking an otherwise valid update.
- Updating to the same version shows both versions explicitly. Release selection, local-change protection and setup behavior are unchanged.

No migration is required. Run `plex update` to install this patch. The new display becomes available after this patch is installed; an older updater keeps its earlier output during that initial update.

Verification: 252 local tests passed, including release selection, output before fetch, preview, first install, same-version updates, missing/invalid metadata and CLI formatting. Remote installations and live chat behavior were not evaluated.

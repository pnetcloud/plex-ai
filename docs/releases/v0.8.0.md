# Plex AI v0.8.0

Goal token budgets are now optional and unlimited by default from Plex's side.

- `.plex/preset.toml` supports separate `coordinator_token_budget` and
  `subagent_token_budget` settings.
- A missing setting or `0` means Plex omits the native token cap. A positive value
  requests that cap for the corresponding role.
- Goal assignments no longer need a token budget when the effective setting is
  unset. Explicit positive budgets remain supported.
- All native plugin manifests are updated to v0.8.0.

This does not remove host/provider limits or guarantee that a client can keep a
session running indefinitely.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Refresh the team setup and open a new client session to load the updated plugin
and instructions.

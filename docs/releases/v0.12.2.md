# Plex AI v0.12.2

This release includes the Reconfigure fix prepared for v0.12.1, whose publication was blocked by CI. The new regression test now isolates BMad runtime availability instead of depending on the maintainer environment.

Selecting a new profile through interactive Reconfigure no longer stops because managed role files were edited manually.

Interactive **Reconfigure** shows edited receipt-owned role paths, backs up their previewed content and regenerates them from the selected profile and preset overrides. **Update only** still stops on manual edits. Missing or unmanaged files, symlinks, edited instruction blocks, client configuration conflicts and changes after preview remain protected. Put durable model choices in `.plex/preset.toml`.

Install this release and choose Reconfigure again. Existing preset overrides remain in effect; reconfiguration does not turn manual role-file edits into new overrides. No models or permissions change until the installation plan is applied. Configuration tests do not establish live model routing.

# Plex v0.5.1 — Preview

A clearer terminal interface for setup and maintenance.

- Consistent headings, aligned settings and agent/model tables, with bold emphasis
  and terminal-aware colors for commands, success, warnings and errors.
- Compact installation plans show the instruction-file path without dumping the
  full template. Narrow terminals stack agent settings instead of squeezing tables.
- Menus show clear choice titles and details for the selected option, without full-row
  highlighting. Help groups options by purpose and includes command examples.
- Status and uninstall have readable human summaries; `--json` preserves plain
  machine-readable stdout for status, removal previews, removal and cancellation.
- Redirected output, `NO_COLOR` and `TERM=dumb` stay plain. Plain interactive menus
  use numbered choices. Source downloads report progress without raw Git clone noise.
- Shell commands stay copyable; setup's next commands use the current entrypoint
  when the optional `plex` shortcut is unavailable.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Try `plex --help`, `plex status`, or preview setup from a project:

```sh
plex --dry-run --client codex --project .
```

Use `plex uninstall --dry-run --json` for a machine-readable removal plan.

## Validation and limits

135 local tests passed. Real terminal checks at 80 and 40 columns verified ANSI
styling and responsive layout; an interactive terminal run selected Balanced,
reached confirmation and cancelled without project writes. JSON and plain-output
behavior have dedicated tests. Publication requires Linux/macOS CI with Python
3.11/3.14. Native checks skip when a client CLI is unavailable.
No model calls or new quality/cost benchmarks were run. This remains a preview.

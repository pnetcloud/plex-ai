# Plex v0.5.4 — Preview

Coordination hotfix: visible role binding and assignment names.

- Put native `plex-<role>` dispatch at the beginning of the skill and both coordinators.
- Use `plex_<role>_<short_task>` task names and `[plex:<role>:<short_task>]` message labels. Keep current labels when reusing a thread; host nicknames may remain unchanged.
- Report unavailable roles or routing conflicts instead of silently using a generic agent.
- Read instructions separately and recover truncated sections before delegation.
- Move detailed BMad workflow rules into a separately loaded contract, preserving workflow checks and project adapters.
- Carry verified paths, ownership, evidence and the next gate in a compact continuation checkpoint.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Run setup to update the shared package and refresh managed project instructions, then reopen the client and invoke Plex. Existing running threads are not rewritten.

## Validation

138 local tests passed, including packaging the separate workflow contract for all three clients. Relative links and preservation of the moved BMad rules were checked. Publication requires Linux/macOS CI with Python 3.11/3.14. No fresh model delegation was run; package checks do not establish live routing. This remains a preview.

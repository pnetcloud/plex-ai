# Plex AI v0.6.0

Reliable auto-mode handoffs and native Codex role selection.

## Changes

- Existing uncommitted changes alone no longer require confirmation. Preserve foreign files and pre-existing hunks in assigned files; pass that authorization to BMad workflows. Actual scope conflicts, production restrictions and required reviews remain in force.
- Codex setup exposes native role selection using managed `hide_spawn_agent_metadata = false` and `tool_namespace = "agents"` settings. Existing personal values are preserved; conflicting values are reported. Backups, refresh, rollback and uninstall cover the owned settings.
- Preflight distinguishes missing tools, hidden selectors, rejected roles and accepted calls. Fresh-context handoffs carry interaction mode, ownership and existing authorization.
- Updated Plex AI by pNet presentation, approved Triad reference, dynamic badges, workflow illustration and documentation navigation in four languages.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Choose **Update only**, ensure Codex trusts the project, then open a **new client session**. Existing sessions do not automatically gain the new role controls. Older installers cannot read the new routing receipt; use v0.6.0 or later to manage these installations.

## Verification

- 167 local tests: 166 passed; the native Claude CLI test was skipped because the CLI was unavailable.
- Actual Codex CLI calls confirmed `plex-dev` on Luna / max and `plex-reviewer` on Sol / medium. A Luna / max coordinator completed an installed BMad Build on a dirty tree, including review and verification, while preserving both an unrelated file and an existing hunk inside the edited file.
- A genuine missing artifact-write authorization returned a blocker without asking; the same assignment resumed after explicit authorization.

These are selected native trials, not a guarantee of unattended completion or coverage of every Desktop client. No production application was changed during testing.

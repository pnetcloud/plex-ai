# Plex v0.5.3 — Preview

Clearer setup and profile-specific coordinator recommendations.

- Shorten profile menus; show effective subagent models in the final plan.
- Separate the root coordinator (your main chat) from the installed subagents.
- Store Codex coordinator recommendations in both teams' model profiles:
  Basic Luna/high, Plus Sol/low, Pro Sol/medium, Pro+ Sol/high.
- Keep the main-chat model under the user's control. `inherit` has no specific recommendation.
- Fix spacing between CLI labels and values, including project skill paths.
- Explain coordinator responsibilities and model selection in all four languages.

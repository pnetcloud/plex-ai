# Plex v0.3.0 — Preview

One source per agent, explicit BMad workflow selection and configurable interaction.

- Each team owns one Markdown source per agent. Setup compiles Codex, Claude Code
  and Antigravity formats, preserving their existing tool and access settings.
  The `pnet` and `bmad` teams remain independent.
- The BMad team catalog describes 19 operations across seven roles, including
  internal PO operation codes. The coordinator selects a workflow from the checked
  snapshot; the subagent loads only that workflow from installed BMad.
- Add `interactive`, `balanced` (default) and `auto` interaction modes. Configure
  `interaction` in the preset or pass `--interaction auto` to setup. A user may
  explicitly override the mode for one task without changing saved configuration.
- Subagents return questions to the coordinator. Auto returns partial results and
  blockers instead of waiting, while independent authorized work can continue.
  Supported BMad headless contracts are used without skipping required reviews,
  validation or user authorization.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Existing users can run `plex update`. Refresh selected client installations and
reopen the coding client to load updated skills, coordinator instructions and
snapshots. Existing installation receipts remain supported. Without a saved
interaction preference, the refreshed configuration uses `balanced`.

## Validation and limits

104 local tests passed. Release publication requires Linux/macOS CI on Python
3.11 and 3.14; native-client tests skip when their CLI is unavailable.
No new model benchmark or live interaction-mode evaluation was run. Auto is an
instruction policy, not a guarantee that every BMad workflow can finish unattended.
Unresolved mandatory checkpoints remain blockers; auto does not authorize analyst
research, publication, destructive actions or expanded scope.

# Plex AI v0.10.0

Validated subagent responses and clearer help requests.

- Responses identify the assignment, revision and role. Completion requires evidence for every acceptance criterion.
- Separate progress, decision requests, blockers and completion. The coordinator routes decisions and resumes the same executor with changed evidence or inputs.
- Preserve existing assignment-check CLI behavior, initial PM intake and BMad-owned leaf contracts. No periodic timer, token budget or automatic model switching is added.

Run `plex update`, refresh the project and open a new client session. Legacy input contracts remain readable; attach task identity before checking responses. Do not restart active work solely to add identity.

Validation checks structure, not the truth of evidence or actual delivery. Tests cover response validation and client packaging/installation; live reductions in loops, time or tokens have not been established.

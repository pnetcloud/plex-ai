# Plex AI v0.12.0

Both `pnet` and BMad now offer six model tiers: Basic, Plus, Pro, Pro+, Ultra and Ultra+. Shared setup exposes the new tiers for Codex, Claude Code and Antigravity.

## What changed

- Plus and Pro keep lightweight development models. Pro+ uses Sol/Sonnet for development and review; Ultra introduces Astra/Opus for selected specialist roles while keeping Sol/Sonnet development. Ultra+ increases reasoning effort.
- PM and PO have independent settings in BMad. The pnet explorer and QA have their own settings rather than borrowing another role's full configuration.
- Every provider file places the coordinator recommendation first within each tier. It remains guidance for the main chat, not an extra subagent or an automatic model switch.
- Setup instructions use the selected team's resolver catalog. Menus, model comparisons, configuration and installation guides cover all six tiers in English, Russian, German and Simplified Chinese.

## Updating

Existing profile IDs and project overrides remain valid. Update Plex, preview the effective settings, then refresh every configured client. A saved profile name does not freeze its previous model choices: this release changes Plus, Pro and Pro+ definitions. The former Pro+ Astra/Opus specialist mix is now represented by Ultra; inspect the complete plan before choosing a tier. Overrides continue to take precedence. Open a fresh client session to load refreshed role settings.

The installer does not change your main-chat model or deploy to other projects. Native Google profiles use Flash or inherit the main-chat model, so Ultra is not a separate pinned Gemini model. Claude on Antigravity uses exact requested IDs, whose native routing still requires host support; Sonnet substitutes for Haiku where Haiku is absent from the host catalog.

## Verification and limits

Regression coverage includes profile resolution, coordinator separation, role ordering, provider mappings, six-tier menu previews, native rendering and isolated installation. These checks do not establish equivalent quality, actual model routing or cost savings across providers. The release workflow runs the Linux/macOS Python matrix and clean Docker installation before publishing.

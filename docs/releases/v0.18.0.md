# Plex AI v0.18.0

Claude Code setup now grants managed, narrow access to the installed Plex package and its read-only checkers, so source installation and cached plugin execution use the same package path.

- Use the native inventory's actual install path, explicitly update existing Claude plugin caches and preserve that path on roles-only refresh.
- Preserve personal settings and rules. Edited owned rules block refresh; backup/rollback and uninstall use the existing ownership transaction. BMad adds skill reads, not blanket runtime execution.
- Install Claude BMad skills with `--copy`, keeping shared Codex copies separate. Other clients retain their existing installation behavior.
- Pass the verified package path inside Markdown assignment Inputs. Keep Markdown contracts, legacy JSON compatibility and workflow-owned formats; no free-form prefix before the contract.

Run `plex update` with normal plugin installation, then restart Claude to load the refreshed plugin and roles. Roles-only refresh does not update a native plugin cache. Existing assignments need not restart just to change format.

Verification: 268 local tests passed, including Claude CLI 2.1.310 cache upgrades and checkout installation, both-team configuration, personal-rule preservation, uninstall, rollback, symlinks and concurrent edits. Coverage does not establish every model/profile combination or active-session loading.

A separate live Haiku check in `dontAsk` mode recorded real Read and Bash calls against the installed cache and validator, with no permission denials. It did not activate a team workflow or verify child-agent routing.

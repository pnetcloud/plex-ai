# Plex v0.5.10

Clear coordinator delegation, stronger CI and a smoother final confirmation.

- The final **Apply this plan?** prompt defaults to Yes for setup and refresh. No still cancels; uninstall and archiving other agents retain separate confirmation.
- Coordinator instructions explicitly require native subagent calls for substantive work, including after follow-ups and context compaction. Small mechanical actions and coordination remain local.
- Add local Markdown-link checks and a clean Docker installation lifecycle for all three clients at project and user scope. The container uses bare Python without uv or client CLIs, no network and an unprivileged user.
- Release publication requires the Linux/macOS Python 3.11/3.14 matrix and the Docker check to pass.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Refresh setup, open a new client session and invoke Plex to load the updated coordinator instructions.

## Validation

162 local tests and six clean-container lifecycle scenarios passed. Native Windows and live model behavior were not tested.

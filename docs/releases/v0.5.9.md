# Plex v0.5.9

Active-team dispatch and optional legacy-agent cleanup.

- Plex-owned assignments may use only exact native roles in the checked active team. Unrelated, built-in and stale roles are excluded, including inactive names with a plex- prefix. Workflow-owned executors retain their workflow contract.
- Codex setup lists other agent files only when found. Keep is the default; moving eligible files to a backup requires an explicit selection or `--archive-other-agents`.
- Cleanup is limited to the selected installation scope. Backups preserve file contents; preview hashes and apply rollback protect against changed files and failed role setup.
- Symlinks, explicit `config.toml` registrations and managed roles are preserved. Edited managed files remain conflicts.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Update setup to refresh the managed instructions and roles, then open a new client session. Existing installations are not changed merely by downloading the package.

## Validation

161 local tests passed, including default preservation, conditional prompts, cancellation, dry runs, backup verification, concurrent edits, rollback, user/project isolation and multi-client setup. No live model trial was run.

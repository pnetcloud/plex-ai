# Plex v0.2.0 — Preview

Maintenance commands and reproducible installation for external testing.

- `plex status` reports version, scope, team/profile, native roles, plugin discovery and conflicts; `--json` supports tooling.
- Installation and `plex update` select published releases, including previews. Pin with `--release`; opt into `main` with `--development`. Dirty or unrelated checkouts are preserved.
- Portable tests are public. Linux/macOS CI checks Python 3.11/3.14 and gates release publication; native-client tests skip when their CLI is absent.
- `plex uninstall` previews/confirms scoped removal, checks receipt hashes, preserves foreign/edited files and shared instruction blocks, and backs up removed state. Interruptions and caught errors roll back when possible.

## Try it

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Run in your project directory. Shared plugins, source checkout, CLI shortcut, preset preferences and backups remain after scoped uninstall. Project preferences retain their precedence; scope does not switch automatically. Reopen the coding client after changes.

This is a prerelease. No new model benchmark was run; native Claude Code live routing and the existing benchmark limitations remain unchanged.

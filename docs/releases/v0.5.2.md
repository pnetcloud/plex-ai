# Plex v0.5.2 — Preview

A shorter Quick start and a structured installation reference. Installer behavior is unchanged.

- Quick start shows standard installation and the Codex `--dev` alternative.
- Remove demo-directory creation and keep prerequisites in the installation guide.
- Replace long installation prose with task/command tables, separate dev and BMad
  sections, grouped options and concise troubleshooting. All CLI options remain documented.
- Explain the source-checkout command when `plex` is unavailable after a fresh dev install.
- Update English, Russian, German and Chinese documentation together.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Dev mode for Codex, from your project directory:

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash -s -- --dev --client codex
```

## Validation

135 local tests passed. Documentation links, all 25 setup flags and dev argument
forwarding were checked. Publication requires Linux/macOS CI with Python 3.11/3.14;
native checks skip when the client CLI is absent. No additional manual installation or model
session was run for this documentation release. This remains a preview.

# Plex AI v0.9.0

Plex no longer manages token budgets.

- Remove token-budget settings, assignment checks and manager/worker budget instructions.
- Refresh removes retired fields from older presets while preserving team, profile, interaction, concurrency and model overrides.
- Acceptance criteria, genuine blockers and native host constraints still apply. The concurrent-assignment limit is unchanged.

```sh
plex update
```

Refresh your project and open a new client session. Existing chats may retain old instructions; existing native Goals are not modified.

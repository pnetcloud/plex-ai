# Plex v0.3.1 — Preview

Fix setup stopping when `~/.local/bin/plex` already exists.

- Normal setup keeps a command from another checkout, a foreign file or a broken
  link and continues configuring the selected project or user scope.
- A notice identifies the retained command and shows the current checkout's
  entrypoint. No existing command is overwritten.
- Explicit `--install-command` retains its conflict protection. Existing shortcuts
  owned by this checkout remain reusable and upgradeable.

## Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Rerun the command from your target project. A retained shortcut still points to
its existing checkout; use the printed entrypoint to run the newly downloaded copy.

105 local tests passed, including setup with another checkout's shortcut, a foreign
file and a broken link. Publication requires Linux/macOS CI on Python 3.11/3.14.
No model calls or new benchmarks were run.

# Plex AI v0.14.0

PM 现在会从完整的角色工作流映射中选择最精简且合适的 BMad 路径。目录新增了 PM 的简明规范 `bmad-spec`、PO 的史诗与用户故事拆分、Sprint 计划和路线修正工作流，以及 Dev 的 walkthrough 直接入口。现有 PO 操作仍然保留。

直接进入工作流时，遵循所选已安装 skill 自身的激活与返回契约，无需先激活无关 persona。通过 persona 或菜单进入时，仍使用其声明的绑定和操作。缺少 `operation` 本身并不能证明支持直接入口。Root coordinator 仍是唯一的派发者。

Build 会复用已接受的需求。若需求尚不具体，只有选定的规范工作流，或其已安装契约支持最小规范工作的 Build 路径，才能在编写代码前补齐。Plex 不会自动创建 PRD、史诗、用户故事或重复规范。`interactive` 模式下，PM 通过 root 返回有实质差异的路径选项和建议；`auto` 模式下由 PM 自行选择；`balanced` 保持现有规则。已确定的选择以及所选工作流的实际审查和检查关卡均会保留。

任务 schema、已保存 preset、会话状态格式、profile、model 和 pnet 行为均未改变。现有 `.plex/resolved.json` 快照不会自动更新；刷新所选项目配置即可获取新目录。目录条目不会安装 BMad skills，也不能证明目标主机具备该 skill。resolver、生成角色、软件包和文档检查不能证明当前聊天已加载更新，也不能保证工作流会无人值守地完成。

# Plex AI v0.17.1

`plex update` 现在会在下载前显示当前源码版本及所选目标，例如 `Plex update: v0.17.0 → v0.17.1`。

- 预览显示相同的版本变化，不修改文件。
- 首次安装显示 `not installed`；无法读取当前版本元数据时显示 `unknown`，不会阻止原本有效的更新。
- 更新到同一版本时也会明确显示两个版本。版本选择、本地修改保护及安装流程保持不变。

无需迁移。运行 `plex update` 安装此补丁。新显示方式在安装此补丁后生效；旧更新器在首次更新过程中仍使用原有输出。

验证：本地通过 252 项测试，覆盖版本选择、fetch 前的输出、预览、首次安装、相同版本、缺失或无效元数据以及 CLI 格式。未评估远程安装和真实聊天行为。

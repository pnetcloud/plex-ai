# Plex v0.5.11

稳定 macOS CI、协调者委派及安装默认值。

- ARM runner 在测试启动前分配失败后，将 macOS CI 固定到受支持的 `macos-15-intel` 资源池。保留两个 Python 版本及完整发布检查。
- 安装和刷新时，最后的 **Apply this plan?** 默认选择 Yes。No 仍可取消；卸载和归档其他代理保留独立确认。
- 协调者指令明确要求使用原生子代理调用完成实质性工作，包括后续请求及上下文压缩之后。小型机械操作和协调工作仍在主对话中完成。
- 增加本地 Markdown 链接检查，以及三个客户端在项目和用户范围中的纯净 Docker 安装生命周期检查。容器使用无 uv 或客户端 CLI 的 Python，禁用网络并以非 root 用户运行。
- 发布要求 Linux/macOS、Python 3.11/3.14 矩阵及 Docker 检查均成功。

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

刷新配置，打开新客户端会话并调用 Plex，以加载新的协调者指令。

## Validation

162 项本地测试和六个纯净容器安装场景通过。未测试原生 Windows 或模型运行行为。

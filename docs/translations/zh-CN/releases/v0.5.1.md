# Plex v0.5.1 — Preview

更清晰的安装与维护终端界面。

- 统一标题、对齐设置和智能体/模型表格；用粗体及终端颜色突出命令、成功、警告和错误。
- 紧凑计划显示指令文件路径，不再输出完整模板。窄终端逐项显示智能体设置。
- 菜单显示清晰标题及所选项说明，不突出整行背景。帮助按用途分组参数，并提供示例。
- 状态和卸载使用可读摘要；`--json` 为状态、卸载预览、卸载及取消保持纯 JSON stdout。
- 重定向、`NO_COLOR` 和 `TERM=dumb` 使用纯文本；简单交互菜单使用编号。
  源码下载显示进度，不再直接输出 Git clone 信息。
- 命令保持可复制。可选的 `plex` 命令不可用时，后续提示使用当前入口。

## 安装或更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

可尝试 `plex --help`、`plex status`，或在项目目录中预览安装：

```sh
plex --dry-run --client codex --project .
```

机器可读卸载计划：`plex uninstall --dry-run --json`。

## 验证与限制

135 项本地测试通过。在 80 和 40 列的真实终端检查颜色和布局；交互测试选择 Balanced，
到达确认步骤并取消，未写入项目。JSON 和纯文本输出有专门测试。
发布要求通过 Linux/macOS 和 Python 3.11/3.14 CI；缺少客户端 CLI 时跳过原生检查。
未调用模型，未进行新的质量或成本基准测试。此版本仍为预览版。

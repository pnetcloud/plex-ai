# Plex AI v0.8.1

Codex 角色从主聊天继承权限。

- 角色 TOML 不包含 `sandbox_mode` 或 `approval_policy`。请在主会话配置权限和 MCP 服务器。
- 只读角色指令仍是行为边界，不构成独立沙箱。Claude Code 和 Antigravity 的工具限制保持不变。
- 刷新会备份未修改的受管角色并删除旧沙箱字段。手动修改仍会触发冲突，不会被覆盖。

## 更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

刷新团队配置并打开新的客户端会话，以加载更新后的角色。

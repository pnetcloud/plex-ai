# Plex AI v0.19.3

两个 Plex 团队的 OpenAI 配置中，原先选择 Sol 和 Astra 的位置现在使用 **GPT-6.2 Sol**（`gpt-6.2-sol`）和 **GPT-6.2 Astra**（`gpt-6.2-astra`）。

- 更新 `pnet` 和 `bmad` 的角色模型，包括 Ultra 和 Ultra+ 的 Sol 协调器建议。
- 保留角色分配和推理强度。Luna、Terra、Claude Code 和 Antigravity 设置不变。
- 同步英文、俄文、德文和中文主 README。历史评估结果保留实际测试时的模型版本。

运行 `plex update` 并保留团队及档位，以应用新默认值。项目显式覆盖项仍优先生效。打开新的客户端会话以加载更新后的角色。主对话模型建议仍只是建议，请在客户端中选择模型。

验证：完整可移植源码测试套件、配置生成、打包、文档和 shell 语法检查均通过。当前 Codex 模型目录包含两个目标 ID 及所用推理强度。未进行真实模型对比或质量、性能基准测试。无需配置格式迁移。

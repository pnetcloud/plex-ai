# Plex AI v0.8.0

Goal token 预算现已改为可选，默认情况下 Plex 不设置 token 上限。

- `.plex/preset.toml` 支持分别配置 `coordinator_token_budget` 和
  `subagent_token_budget`。
- 未设置该项或值为 `0` 时，Plex 不会传递原生 token 上限；正数表示为相应角色请求上限。
- 有效配置未设置上限时，Goal 任务无需填写 token 预算。仍可明确设置正数预算。
- 所有原生插件清单版本更新至 v0.8.0。

客户端或服务提供方仍可能施加自己的限制；这不保证会话可以无限期运行。

## 更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

刷新团队配置并重新打开客户端会话，以加载更新后的插件和说明。

# Plex v0.5.2 — Preview

更简短的快速开始与结构化安装参考。安装器行为保持不变。

- 快速开始提供普通安装与 Codex `--dev` 两种命令。
- 移除演示目录创建步骤，将依赖要求保留在安装指南中。
- 用任务/命令表、独立 Dev/BMad 章节、分组参数和简短故障排查替代长篇说明。
  全部 CLI 参数仍有文档。
- 说明首次开发模式安装后缺少 `plex` 命令时如何使用工作副本入口。
- 同步更新英、俄、德、中四种语言。

## 安装或更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

在项目目录使用 Codex 开发模式：

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash -s -- --dev --client codex
```

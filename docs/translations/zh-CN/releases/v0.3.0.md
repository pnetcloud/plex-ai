# Plex v0.3.0 — Preview

每个智能体一个源文件、明确的 BMad 工作流选择，以及可配置的交互模式。

- 每个团队为每个智能体维护一个 Markdown 源文件。安装器生成 Codex、Claude Code
  和 Antigravity 格式，保留原有工具与访问设置。`pnet` 和 `bmad` 团队相互独立。
- BMad 目录描述七个角色的 19 项操作，包括 PO 内部操作代码。协调者从已检查的
  快照选择工作流；子智能体仅加载已安装 BMad 中被选中的工作流。
- 新增 `interactive`、`balanced`（默认）和 `auto`。可在 preset 中设置 `interaction`，
  或向安装器传递 `--interaction auto`。用户明确指定的单次任务模式不会改写保存的配置。
- 子智能体将问题返回协调者。Auto 不等待输入，而是返回部分结果与阻塞原因，继续独立且
  已授权的工作。在支持时使用 BMad 原生 headless 合约；仍保留必需审查、验证及用户授权。

## 安装与更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

现有用户可运行 `plex update`。刷新所选客户端安装并重新打开客户端，以加载新的技能、
协调者指令及快照。现有安装记录仍受支持。没有保存模式时，刷新后的配置使用 `balanced`。

## 验证与限制

本地通过 104 项测试。发布需要 Python 3.11 和 3.14 的 Linux/macOS CI 通过；
没有对应 CLI 时跳过原生客户端测试。未进行新的模型基准测试或交互模式的实际模型验证。
Auto 是指令策略，不保证所有 BMad 工作流均可无人值守完成。未解决的必需检查点仍会阻塞；
auto 不授予分析师研究、发布、破坏性操作或扩大任务范围的权限。

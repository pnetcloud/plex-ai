# Plex AI v0.18.0

Claude Code 安装器现在管理对已安装 Plex 包及只读校验器的限定访问，使源码安装与缓存插件执行使用相同的包路径。

- 从原生清单获取实际安装路径，显式更新已有 Claude 插件缓存，并在仅角色刷新时保留路径。
- 保留个人设置与规则。修改托管规则会阻止刷新；备份、回滚和卸载沿用现有所有权事务。BMad 仅增加技能读取权限，不授予通用 runtime 执行权限。
- Claude 的 BMad 技能使用 `--copy`，与 Codex 共享副本分离。其他客户端的安装行为保持不变。
- 在 Markdown Inputs 内传递经过核验的包路径。保留 Markdown 契约、旧 JSON 兼容性及工作流格式，不在契约前添加自由文本前缀。

通过常规插件安装运行 `plex update`，然后重启 Claude 以加载更新后的插件与角色。仅角色刷新不会更新原生缓存。无需因格式变化而重启进行中的任务。

验证：本地通过 268 项测试，覆盖 CLI 2.1.310 缓存升级、从 checkout 安装、两个团队的配置、个人规则保留、卸载、回滚、符号链接及并发修改。这不证明所有模型或配置组合，也不证明活动会话已加载更新。

另一次 Haiku `dontAsk` 实测记录了针对已安装缓存和校验器的真实 Read、Bash 调用，未发生权限拒绝。该检查未激活团队工作流，也未验证子智能体路由。

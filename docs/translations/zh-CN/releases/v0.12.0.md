# Plex AI v0.12.0

`pnet` 和 BMad 两个团队现在均提供六个模型档位：Basic、Plus、Pro、Pro+、Ultra 和 Ultra+。Codex、Claude Code 与 Antigravity 的共享安装流程均可选择新档位。

## 变更

- Plus 和 Pro 保留轻量开发模型。Pro+ 使用 Sol/Sonnet 进行开发和审查。Ultra 为部分专家引入 Astra/Opus，同时保留 Sol/Sonnet 开发。Ultra+ 提高推理强度。
- BMad 中的 PM 和 PO 使用独立设置。pnet 的 Explorer 和 QA 根据各自任务单独配置。
- 每个提供商文件在各档位中首先列出协调器建议。这只是主会话建议，不会新增子智能体，也不会自动切换主模型。
- 安装指令依据所选团队的解析器目录。菜单、模型对比、配置与安装指南均以英语、俄语、德语和简体中文覆盖六个档位。

## 更新

现有配置档 ID 和项目覆盖设置仍然有效。更新 Plex、预览有效设置，再刷新每个已配置客户端。保存的档位名称不会冻结旧模型选择：本版本调整了 Plus、Pro 和 Pro+。原 Pro+ 的 Astra/Opus 专家组合现在由 Ultra 表示；选择前请检查完整计划。覆盖设置继续优先。打开新的客户端会话以加载刷新后的角色。

安装器不会更改主会话模型，也不会部署至其他项目。Google 原生配置使用 Flash 或继承主会话模型，Ultra 不会固定为单独的 Gemini 模型。Antigravity 中的 Claude 使用具体请求的模型 ID，其原生路由仍需客户端支持；主机目录缺少 Haiku 时使用 Sonnet 替代。

## 验证与限制

回归检查涵盖配置解析、协调器与角色分离、角色顺序、提供商映射、六档位预览、原生渲染及隔离安装。这些检查不能证明不同提供商具有相同质量、实际模型路由或成本节省。发布工作流在发布前运行 Linux/macOS/Python 矩阵与纯净 Docker 安装检查。

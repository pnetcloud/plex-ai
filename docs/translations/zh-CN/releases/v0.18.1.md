# Plex AI v0.18.1

Codex Pro 现在在 `pnet` 和 `bmad` 团队中使用 GPT-6.1 Terra 进行开发，保留原有的 `max` 推理强度。

- 协调器建议：Pro 使用 Terra / `medium`，Pro+ 使用 Terra / `high`。
- Pro+ 开发者仍使用 Sol / `medium`；其他角色和提供商的设置保持不变。
- 已更新协调器输出，并同步四种语言的配置文档。

运行 `plex update` 并保留团队和配置档位，以应用新的默认值。项目自定义覆盖项仍优先生效。请在主对话中选择建议的协调器模型；Plex 不会切换正在运行的对话模型。打开新的客户端会话以加载更新后的角色。

验证：配置、CLI 输出、文档检查和完整本地测试套件均已通过。这些检查不证明 Terra 在上述角色中的实际路由、质量或性能。无需格式迁移。

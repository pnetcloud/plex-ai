# Plex AI v0.10.0

可验证的子智能体响应与清晰的求助请求。

- 响应标明任务、修订号和角色。完成状态要求每个验收项均有证据。
- 区分进展、决策请求、阻碍和完成。协调器将问题交给决策负责人，再由同一执行者根据新证据或修正输入继续。
- 保留原有任务检查 CLI、初始 PM 评估和 BMad 内部步骤契约。不增加定时器、token 预算或自动模型切换。

运行 `plex update`，刷新项目配置并打开新的客户端会话。旧输入契约仍可读取；检查响应前补充任务身份，不要仅为此重启正在进行的工作。

验证检查结构，不证明证据真实或消息已送达。测试覆盖响应验证、打包和客户端安装；尚未证明实际运行中的循环、时间或 token 消耗有所减少。

# Plex AI v0.7.0

由 PM/PO 定义任务，并在明确边界内执行至结果得到验证。

- PM/PO 选择常规执行、先规划或目标导向执行，提供一至五个可观察验收标准。Root 负责调度并整合证据。
- 简洁 JSON 契约和只读验证器根据已检查的团队快照验证角色、输入、范围、就绪状态和执行设置。现有 issue/spec/story 仍为权威来源。
- 原生 Plan/Goal 模式是可选能力；不可用时照常规划或在范围内按标准推进。原生 Goal 默认请求 50,000 token，不自动续期；无法计量时明确说明未强制执行预算。
- 支持已安装的 `bmad-build-auto` 执行一轮无人值守迭代。保留 renderer、必需子代理、review 和终止协议；复用已接受规格，不额外套一轮规划。
- 复用代理并仅传递变化的信息。未完成任务额度与原生线程槽分别计数；保持精确的工件路径与修订，不替换为名称相似的文件。

## 更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

刷新设置并开启新客户端会话，以加载更新的角色指令与 workflow 目录。团队成员、模型配置档及安装器配置接口保持不变。

验证：174 个本地测试（173 通过，因缺少 Claude CLI 跳过一个）；全部客户端与两种作用域的六轮离线 Docker 安装生命周期通过。原生 pnet 执行与一轮已安装 BMad Build Auto 完成，包含四个 workflow review 子代理。测试宿主无法初始化 `bwrap`，因此 live smoke 未使用沙箱；未验证原生 Goal 激活、预算强制执行或自动续跑。

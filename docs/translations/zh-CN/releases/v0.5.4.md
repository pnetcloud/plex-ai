# Plex v0.5.4 — Preview

协调热修复：明确角色选择与任务命名。

- 将原生 `plex-<role>` 角色选择放在技能和两个协调者指令的开头。
- 使用 `plex_<role>_<short_task>` 任务名和 `[plex:<role>:<short_task>]` 消息标签。复用线程时提供当前任务标签；系统昵称可能保持不变。
- 明确报告不可用角色或路由冲突，不得静默改用通用智能体。
- 分开读取指令，并在委派前补读被截断的部分。
- 单独加载详细 BMad 工作流契约，保留工作流检查和项目适配器。
- 使用简短的继续执行检查点，保留已验证路径、写入责任、证据和下一检查点。

## 更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

运行安装器以更新共享包和托管的项目指令，然后打开新的客户端会话并调用 Plex。已运行的线程不会被改写。

## 验证

138 项本地测试通过，包括三个客户端的独立契约打包检查。已检查相对链接和迁移后的 BMad 规则完整性。发布须通过 Linux/macOS、Python 3.11/3.14 CI。未执行新的模型委派；包测试不能证明实际路由。本版本仍为预览版。

# Plex v0.5.3 — Preview

更清晰的安装计划，以及按配置档给出的协调者模型建议。

- 简化配置档菜单，在最终计划中显示子智能体的有效模型设置。
- 将根协调者（主对话）与安装的子智能体分开显示。
- 两个团队的模型配置文件都保存 Codex 协调者建议：
  Basic Luna/high、Plus Sol/low、Pro Sol/medium、Pro+ Sol/high。
- 主对话模型由用户选择，`inherit` 不提供具体建议。
- 修复 CLI 标签与值之间的间距，包括项目技能路径。
- 使用四种语言解释协调者职责和模型选择。

## 安装或更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash -s -- --dev --client codex
```

138 项本地测试通过。已在终端检查键盘选择及取消，并检查 40 和 80 列下的计划输出。

没有调用模型或运行新的效率基准。请刷新安装配置以更新生成的快照。本版本仍为预览版。

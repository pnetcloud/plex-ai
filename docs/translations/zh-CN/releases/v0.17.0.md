# Plex AI v0.17.0

Plex 管理的智能体任务和响应现在使用易读的 Markdown，包含固定标题、字段和列表。两个团队使用相同的模板与校验器。

- 保留任务标识、修订号、角色、就绪状态、执行方式以及一至五项可验证的验收标准。
- 对照当前任务校验进度、决策请求、阻塞和已完成响应，包括各项验收证据。拒绝格式错误的列表、未知契约章节和重复字段。
- 旧 JSON 契约仍可读取，任务与响应也可混用两种格式。无需重启进行中的工作或重写历史文件。
- 协调路由及工作流自有的返回格式保持不变。原生工具调用的外层结构和显示方式由客户端控制；校验器的诊断输出仍为 JSON。

运行 `plex update` 并应用配置以更新角色指令。开启新的客户端会话以加载更新后的指令。历史契约不会自动重写。

验证：本地通过 250 项测试，覆盖 Markdown 模板、所有响应状态、无效输入、多行文本与 Unicode、JSON 兼容性、CLI 只读行为，以及三个客户端的包导出。未评估真实智能体行为和聊天显示效果。

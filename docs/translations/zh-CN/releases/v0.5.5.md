# Plex v0.5.5

正式发布版本，修复 Claude Code 委派细节并简化入门文档。

- 使用 `subagent_type` 选择 Claude 角色，在 `description` 和交接文本中添加任务标签。不传入 `name`，避免标签意外触发 Agent Teams 队友。
- 对 `delegation = false` 的角色禁用原生 `Agent` 工具，包括 pnet 的 dev 和 QA。BMad 保留有条件的嵌套委派。
- 增加原生 Claude 验证、隔离环境插件安装和两支团队配置检查，不调用模型。
- 简化 README，添加抽象 Claude 聊天示例，并用四种语言分别说明团队卸载与共享插件卸载。
- 本次及后续版本不再标记为 GitHub prerelease，标题不再包含 Preview。版本仍为 0.x，1.0 前接口可能调整。

## 更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

运行安装程序以刷新插件和托管角色，然后打开新的客户端会话。正在运行的会话不会被改写。

## 验证

139 项本地测试通过，包括 Claude Code 2.1.306 清单验证、隔离配置中的插件安装及 pnet/BMad apply/check。发布需通过 Linux/macOS、Python 3.11/3.14 CI。未运行新的模型任务：这些检查验证安装配置，不证明实际委派、模型可用性或质量。

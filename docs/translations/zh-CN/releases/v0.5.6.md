# Plex v0.5.6

明确任务路线并提供 BMad 激活证据。

- 任务开始时说明路线：有边界的实现、重要规划、诊断或审查。
- 操作前执行 BMad 人格激活，返回技能路径、执行证据和已进入的工作流步骤。
- 区分人格负责人、直接审查与工作流叶子执行者。
- 调查、实现计划及审查由 Build 负责；缺失的上游决策交给对应专家。
- 将技能说明改写为简短规则、步骤和表格，并在受版本控制的 AGENTS.md 中记录写作要求。

## 更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

刷新共享插件和托管角色，然后重新打开客户端并调用 Plex。
缺失的 BMad 技能仍会阻塞相应任务；此版本不安装替代品。

## 验证

139 项本地测试通过，包括包导出和隔离环境原生客户端检查。发布需通过 Linux/macOS、Python 3.11/3.14 CI。未运行 BMad 人格或工作流的实际模型测试；指令修改不能证明模型遵循情况或实际路由。

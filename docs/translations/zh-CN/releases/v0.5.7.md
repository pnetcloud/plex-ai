# Plex v0.5.7

统一协调者结构与贡献指南.

- 将 pnet/BMad 协调者与子智能体统一为清晰内容块：激活、工作方式、重点、检查、返回和边界。
- 保留原生角色选择、激活证据、工作流关卡、写入责任、并发限制和恢复规则。
- 新增 CONTRIBUTING.md，链接现有写作和验证标准；更新四种语言的角色格式说明。

## 更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

通过安装程序刷新插件，然后重新打开客户端并调用 Plex。

139 项本地测试通过，包括包导出和隔离环境原生客户端检查。发布需通过 Linux/macOS、Python 3.11/3.14 CI。未进行实际模型测试；指令更清晰并不能证明模型遵循情况改善。

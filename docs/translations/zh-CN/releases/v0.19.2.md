# Plex AI v0.19.2

Plex 协调器现在核查是否正朝可观察的验收结果推进，而不是仅依赖重复状态消息。

- 连续报告未提供同一里程碑的新证据时，检查引用的产物或检查结果。仅在必要时向同一执行者请求缺失信息；观察未变时复用已有回答。
- 正在推进的实现应继续执行，不反复询问状态、重启 Build 或增加管理循环。组件测试只是部分证据，不等同于集成完成。
- 将检查点的负责人、阻塞项和下一步与当前已接受的任务核对。保留已完成工作、必要专家决策、人工批准和工作流检查。
- 在客户端限制内降低无变化轮询的频率。不新增执行计时器、令牌预算、模型变更或契约模式。

运行 `plex update` 并保留团队和档位。在新会话中加载新指令，或明确将相关规则变更传给现有协调器和复用的执行者。仅更新文件不会改变运行中智能体的初始指令。不要为了采用补丁而重新执行已完成的工作。

验证：完整本地测试套件和 shell 检查均通过，涵盖契约、检查点、文档和打包。场景审查覆盖过时检查点、重复状态以及实际推进的工作。这是提示词指导，不是确定性的循环检测器；实际改善仍需观察。

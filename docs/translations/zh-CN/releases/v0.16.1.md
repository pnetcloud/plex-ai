# Plex AI v0.16.1

Plex 在 `.plex/` 中将 `applied.toml`、`resolved.toml` 和 `skill-aliases.toml` 与 `preset.toml` 一同存储，让生成的配置更易阅读。

- 应用配置时，Setup 自动迁移三个旧 JSON 文件。设置、覆盖项和所有权记录保持不变；原文件经过验证后备份，失败时回滚。
- 只读状态和预览支持旧安装，不修改文件。相同副本会合并，内容冲突的 JSON/TOML 文件保持原样；并发修改和符号链接受到保护。
- `plex status` 显示实际配置格式。任务校验器支持新旧快照，CLI `--json` 输出仍为 JSON。
- 协调器状态明确用于辅助继续工作。协调器仍使用完整的可用会话上下文、已接受的需求和用户修正；检查点中省略的细节不会被取消。

运行 `plex update` 并应用配置即可自动迁移。生成的文件仍由安装器管理；持久设置保存在 `preset.toml`。新客户端会话加载更新后的角色指令，活动会话可能仍保留旧指令。

验证包括 244 项测试，以及 Codex、Claude、Antigravity 在项目级和用户级的干净 Docker 安装检查。迁移检查覆盖数据保留、重复更新、旧安装读取/卸载、冲突、并发写入和回滚。未评估真实模型行为。

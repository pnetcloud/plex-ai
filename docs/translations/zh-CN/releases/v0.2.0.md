# Plex v0.2.0 — 预览版

用于外部测试的维护命令与可复现安装。

- `plex status` 显示版本、范围、团队/配置档、角色、插件发现和冲突；`--json` 提供机器可读输出。
- 安装与 `plex update` 选择已发布版本，包括预览版。用 `--release` 固定标签，用 `--development` 明确选择 `main`。保留已修改或其他项目的副本。
- 可移植测试已公开。CI 在 Linux/macOS 上检查 Python 3.11/3.14，失败会阻止发布；缺少客户端 CLI 时跳过原生检查。
- `plex uninstall` 预览并确认范围内卸载，检查 receipt 哈希，保留其他/已修改文件和共享指令块，并备份移除状态。中断和已捕获错误会尽可能回滚。

## 试用

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

从项目目录运行。范围内卸载后，共享插件、源码、CLI 快捷命令、preset 和备份仍保留。
项目偏好仍优先，不会自动切换范围。修改后打开新客户端会话。

这是预发布版本。没有新增模型基准测试；原生 Claude Code 运行和此前研究限制仍未验证。

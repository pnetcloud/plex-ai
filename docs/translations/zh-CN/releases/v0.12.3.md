# Plex AI v0.12.3

`pnet` 和 BMad 两个团队的四类提供商配置现在采用相同的新版协调器建议阶梯。

Plus 建议 high，Pro 为 xhigh，Pro+ 为 max，Ultra 为 low。Basic 和 Ultra+ 保持不变。OpenAI 在 Pro+ 及以下使用 Luna，Ultra/Ultra+ 使用 Sol；Claude Code 对应使用 Haiku 和 Sonnet。Google 原生配置在 Pro+ 及以下使用 Flash，Ultra 档位继承主会话模型。Antigravity 中的 Claude 保留 Sonnet 替代模型和具体请求的模型 ID。

子智能体模型及推理设置、配置档 ID 和交互模式均未改变。这些仅为主会话建议，安装器不会切换当前模型。更新 Plex 查看新建议，再在客户端选择主模型。配置检查和 CI 不能证明实际路由、质量等价或成本节省。

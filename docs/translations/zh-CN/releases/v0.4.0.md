# Plex v0.4.0 — Preview

通过 Plex 安装器配置 BMad 团队，包括缺失依赖和项目运行时。

- 缺少运行时时，可选择官方初始化、`pnet` 或取消。
- 缺少 setup 技能时，另行批准用户范围的官方技能安装。现有插件保持不变；
  所选用户技能文件可能被替换，并由其他项目共享。
- 仅安装 21 项技能：团队入口和工作流技能、`bmad` 及两个模块记录。
  已验证的官方修订包含插件 marketplace 尚未提供的 PO：
  `495ef6e0996d07b23359cc4d6c73a1aa2f3ba5ad`；安装器为 `skills@1.7.4`。
  不安装仓库中的全部技能。
- `--install-bmad` 授权依赖安装及初始化；`--init-bmad` 使用已有依赖。
  `--yes` 接受显示的模块默认值；`--bmad-skill PATH` 指定 hub；dry-run 不安装。
- 确认计划后由 BMad 官方 setup 创建运行时。Plex 不把技能复制到项目，也不另行实现运行时。

## 安装与更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

在目标项目选择 `bmad` 并按提示安装或初始化。安装依赖需要 Node.js/npm，运行时需要 `uv`。
后续取消或失败不会删除已安装依赖和运行时。完成后重新打开客户端。

## 验证与限制

本地通过 111 项测试。在真实隔离的 Codex 配置中验证了全部 21 项技能、官方运行时和七个原生角色，
未调用模型。Claude Code 和 Antigravity 的命令有可移植测试覆盖，尚未验证其完整实际流程。
未运行新的模型基准测试。发布要求 Python 3.11/3.14 的 Linux/macOS CI 通过。
BMad 是固定修订的预览依赖；仍需在当前客户端检查工作流可用性和实际模型路由。

# Plex v0.3.1 — Preview

修复 `~/.local/bin/plex` 已存在时安装中止的问题。

- 正常安装保留来自其他副本的命令、外部文件或失效链接，继续配置项目或用户范围。
- 提示显示保留的命令及当前副本的启动路径，不覆盖现有命令。
- 显式 `--install-command` 仍保留冲突保护。本副本拥有的快捷链接仍可复用和升级。

## 安装与更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

在目标项目中重新运行。保留的快捷链接仍指向原有副本；请使用安装器显示的路径启动新副本。

本地通过 105 项测试，包括其他副本的快捷链接、外部文件及失效链接。
发布需要 Python 3.11/3.14 的 Linux/macOS CI 通过。未运行模型或新的基准测试。

# Plex v0.5.9

仅使用活动团队角色，并可选择清理旧代理。

- Plex 自有任务只使用已检查的活动团队中的准确原生角色。排除其他、内置及过期角色，包括带 plex- 前缀但不属于活动团队的名称。工作流内部执行者保留其工作流约定。
- Codex 安装器仅在发现其他代理时显示列表。默认保留；只有明确选择或使用 `--archive-other-agents` 时才将可处理文件移至备份。
- 清理仅限所选安装范围。备份保留文件内容；预览哈希检查与应用回滚保护被修改的文件及失败的角色安装。
- 保留符号链接、显式 `config.toml` 注册和托管角色。被修改的托管文件仍报告冲突。

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

刷新安装配置以应用新指令与角色，然后打开新的客户端会话。仅下载包不会改变现有安装。

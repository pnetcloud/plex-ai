# Plex AI v0.6.0

更可靠的 auto 交接与 Codex 原生角色选择。

## 变更

- 未提交的修改本身不再要求确认。保留其他文件及任务文件中已有的修改片段，并将授权传递给 BMad。实际范围冲突、生产环境限制和必要的评审仍然有效。
- Codex 安装程序管理 `hide_spawn_agent_metadata = false` 和 `tool_namespace = "agents"`，支持备份、冲突检查、更新、回滚和卸载，不覆盖个人配置。
- 预检区分工具缺失、角色选择被隐藏、角色被拒绝和调用被接受。使用新上下文交接模式、文件归属与已有授权。
- 更新 Plex AI by pNet 展示：已批准的 Triad 参考图、动态徽章、流程图及四种语言的文档导航。

## 更新

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

选择 **Update only**，确保 Codex 信任项目，然后打开**新会话**。已有会话不会自动获得新的角色选择工具。旧安装程序无法读取新的路由收据；请使用 v0.6.0 或更新版本。

## 验证

167 项本地测试：166 项通过，因未安装 Claude CLI 跳过一项。真实 Codex CLI 调用确认 `plex-dev` 使用 Luna / max，`plex-reviewer` 使用 Sol / medium。Luna / max 协调者在存在未提交修改时完成 BMad Build、评审及验证，同时保留其他文件和目标文件中的已有片段。缺少工作流产物写入授权时，auto 未提问而报告阻塞；获得明确授权后继续同一任务。

这些是选定的原生试验，不保证完全无人值守，也不覆盖所有 Desktop 客户端。测试未修改生产应用。

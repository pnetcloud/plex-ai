# Plex v0.1.0 — 预览版

[English](https://github.com/pnetcloud/plex-ai/blob/v0.1.0/docs/releases/v0.1.0.md) · [Русский](https://github.com/pnetcloud/plex-ai/blob/v0.1.0/docs/translations/ru/releases/v0.1.0.md) · [Deutsch](https://github.com/pnetcloud/plex-ai/blob/v0.1.0/docs/translations/de/releases/v0.1.0.md) · [简体中文](https://github.com/pnetcloud/plex-ai/blob/v0.1.0/docs/translations/zh-CN/releases/v0.1.0.md)

首个公开预发布版本。Plex 在 OpenAI Codex、Anthropic Claude Code 和 Google Antigravity 中配置可复用团队并协调开发智能体。

## 包含内容

- 统一安装器：多客户端选择、项目/用户范围以及共享模型档位。
- `pnet` 与 `bmad` 团队：原生角色、根协调者指令和团队专用配置档。
- 通过 `plex` 显式启动协调；托管指令块保留周围的项目指令。
- 英文文档及俄语、德语和简体中文翻译。
- 汇总测试方法、token/成本测量、协调观察和主观质量评价。
- MIT 许可证及适配第三方指令的署名说明。

## 安装

克隆或下载该标签源码，在所得目录运行 `./setup.sh`。本地 marketplace 仍引用源码或导出目录时，请保留这些目录。所选客户端 CLI 应已安装。BMad 工作流需要另行安装其技能及项目运行时。

## 验证与限制

开发套件通过 76 项测试。档案包含 15 次不同的完成运行，浏览器验收均为 12/12；中止和受阻尝试单独记录。单次运行不能确立普遍效率排名。

Codex 和部分 Antigravity 配置有实际任务证据。原生 Claude Code、常规 Codex 沙箱、纯插件 BMad 运行和屏幕阅读器实际输出尚未验证。工作流内部 reviewer 模型可能与独立角色配置不同。

该预览版用于实验。配置、角色契约和安装行为在 1.0 前仍可能变化。

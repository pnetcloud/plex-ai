# Plex v0.5.8

整理文档并提供 Codex 技能短名称。

- 根目录只保留英文 README，链接到 `docs/translations` 中的俄语、德语和中文项目概览。
- 安装说明统一放入 docs；各语言的指南目录与该语言的 README 放在一起。
- 在项目或用户范围，通过指向共享工作副本的托管链接提供 `$plex` 和 `$plex-setup`。标准模式保持插件启用；开发模式仍仅用于项目。
- 保留其他技能及被修改的链接；更新、状态、卸载和回滚均处理自有链接。

## 更新


# Plex v0.2.0 — Vorschau

Wartungsbefehle und reproduzierbare Installation für externe Tests.

- `plex status` zeigt Version, Bereich, Team/Profil, Rollen, Pluginerkennung und Konflikte; `--json` liefert maschinenlesbare Ausgabe.
- Installation und `plex update` wählen veröffentlichte Versionen einschließlich Vorschauen. `--release` fixiert einen Tag; `--development` wählt ausdrücklich `main`. Geänderte/fremde Checkouts bleiben erhalten.
- Portable Tests sind öffentlich. CI prüft Linux/macOS mit Python 3.11/3.14 und blockiert fehlerhafte Veröffentlichungen; native Prüfungen werden ohne Client-CLI übersprungen.
- `plex uninstall` plant/bestätigt die bereichsbezogene Entfernung, prüft Receipt-Hashes, erhält fremde/geänderte Dateien und geteilte Blöcke und legt Backups an. Unterbrechungen/abgefangene Fehler werden nach Möglichkeit zurückgerollt.

## Ausprobieren

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Im Projekt ausführen. Gemeinsame Plugins, Checkout, CLI-Verknüpfung, Preset und Backups bleiben nach Entfernung erhalten. Projektpräferenzen behalten Vorrang; der Bereich wechselt nicht automatisch. Danach eine neue Clientsitzung öffnen.

Vorabversion. Keine neuen Modellbenchmarks; native Claude-Code-Ausführung und die bisherigen Forschungsgrenzen bleiben ungeprüft.

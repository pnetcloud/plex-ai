# Plex v0.5.7

Einheitliche Koordinatorstruktur und Beitragsleitfaden.

- Für pnet/BMad-Koordinatoren dieselben klaren Blöcke wie für Subagenten verwenden: Aktivierung, Arbeitsweise, Fokus, Prüfungen, Rückgabe und Grenzen.
- Native Rollenauswahl, Aktivierungsbelege, Workflow-Gates, Schreibverantwortung, Limits und Wiederaufnahme bewahren.
- CONTRIBUTING.md als Einstieg zu bestehenden Schreib- und Prüfregeln ergänzen. Rollenformat in vier Sprachen aktualisieren.

## Aktualisieren

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Plugin im Setup aktualisieren, Client neu öffnen und Plex aufrufen.

## Validierung

139 lokale Tests bestanden, einschließlich Paketexporten und isolierten nativen Clientprüfungen. Veröffentlichung erfordert Linux/macOS-CI mit Python 3.11/3.14. Kein Live-Modelltest; klarere Anweisungen belegen keine bessere Modellbefolgung.

# Plex v0.5.3 — Preview

Übersichtlicheres Setup und profilabhängige Empfehlungen für den Koordinator.

- Kürzere Profilmenüs; effektive Subagentenmodelle stehen im abschließenden Plan.
- Root-Koordinator (Hauptchat) getrennt von installierten Subagenten anzeigen.
- Codex-Empfehlungen in den Modellprofilen beider Teams speichern:
  Basic Luna/high, Plus Sol/low, Pro Sol/medium, Pro+ Sol/high.
- Das Hauptchatmodell wählt der Benutzer. Für `inherit` gibt es keine konkrete Empfehlung.
- Abstände zwischen CLI-Beschriftungen und Werten einschließlich Skill-Pfaden korrigieren.
- Koordinatoraufgaben und Modellwahl in allen vier Sprachen erläutern.

## Installieren oder aktualisieren

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash -s -- --dev --client codex
```

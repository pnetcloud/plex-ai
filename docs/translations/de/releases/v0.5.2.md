# Plex v0.5.2 — Preview

Kürzerer Schnellstart und strukturierte Installationsreferenz. Das Installer-Verhalten bleibt unverändert.

- Schnellstart mit normaler Installation und Codex-Alternative `--dev`.
- Demo-Verzeichnis entfernt; Voraussetzungen stehen in der Installationsanleitung.
- Lange Beschreibungen durch Aufgaben-/Befehlstabellen, eigene Dev-/BMad-Abschnitte,
  gruppierte Optionen und kurze Fehlerhilfe ersetzt. Alle CLI-Optionen bleiben dokumentiert.
- Checkout-Einstiegspunkt erklärt, falls nach einer ersten Dev-Installation `plex` fehlt.
- Englische, russische, deutsche und chinesische Dokumentation gemeinsam aktualisiert.

## Installation oder Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Codex-Entwicklungsmodus aus dem Projektverzeichnis:

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash -s -- --dev --client codex
```

## Prüfung

135 lokale Tests bestanden. Dokumentationslinks, alle 25 Setup-Optionen und die
Weitergabe der Dev-Argumente wurden geprüft. Veröffentlichung erfordert Linux/macOS-CI
mit Python 3.11/3.14; native Tests werden ohne Client-CLI übersprungen. Für diesen
Dokumentationsrelease wurde keine zusätzliche manuelle Installation oder Modellsitzung gestartet.
Dies bleibt eine Vorschauversion.

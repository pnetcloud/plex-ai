# Plex AI v0.8.1

Codex-Rollen erben Berechtigungen vom Hauptchat.

- Rollen-TOML enthält weder `sandbox_mode` noch `approval_policy`. Berechtigungen
  und MCP-Server werden in der Hauptsitzung konfiguriert.
- Nur-Lese-Anweisungen bleiben Verhaltensgrenzen und erzeugen keine separate Sandbox.
  Werkzeugbeschränkungen für Claude Code und Antigravity bleiben erhalten.
- Die Aktualisierung entfernt das alte Sandbox-Feld aus unveränderten verwalteten
  Rollen und erstellt Sicherungen. Lokale Änderungen bleiben als Konflikte geschützt.

## Aktualisierung

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Teamkonfiguration aktualisieren und eine neue Clientsitzung öffnen, um die Rollen zu laden.

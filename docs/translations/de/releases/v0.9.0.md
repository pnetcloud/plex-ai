# Plex AI v0.9.0

Plex verwaltet keine Tokenbudgets mehr.

- Budgeteinstellungen, Auftragsprüfungen und Budgetanweisungen für Manager und Entwickler wurden entfernt.
- Refresh entfernt veraltete Felder und erhält Team, Profil, Interaktion, Parallelität und Modellüberschreibungen.
- Abnahmekriterien, tatsächliche Blockaden und Clientbeschränkungen gelten weiterhin. Die Parallelitätsgrenze bleibt unverändert.

```sh
plex update
```

Projektkonfiguration aktualisieren und eine neue Sitzung öffnen. Bestehende Chats können alte Anweisungen behalten; bestehende native Goals werden nicht verändert.

# Plex v0.5.8

Geordnete Dokumentation und kurze Codex-Skill-Namen.

- Eine englische README im Stamm mit Links zu russischen, deutschen und chinesischen Übersichten in `docs/translations`.
- Installationsanleitungen unter docs; übersetzte Anleitungsübersichten liegen neben der README ihrer Sprache.
- `$plex` und `$plex-setup` über verwaltete Links zum gemeinsamen Checkout, im Projekt oder Benutzerprofil. Das Plugin bleibt im Standardmodus aktiv; Dev bleibt projektbezogen.
- Fremde Skills und geänderte Links bleiben erhalten. Eigene Links werden bei Aktualisierung, Status, Deinstallation und Rollback berücksichtigt.

## Aktualisierung

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Setup einmal aktualisieren und eine neue Codex-Sitzung öffnen. Den gemeinsamen Checkout behalten. Neue `roles-only`-Installationen ergänzen keine Skill-Links. Claude Code behält `/pnet-plex:plex`.

## Prüfung

149 lokale Tests bestanden, einschließlich nativer Codex-Erkennung beider kurzen Namen im Projekt und Benutzerprofil. Paketprüfungen umfassen isolierte native Clientinstallationen. Veröffentlichung erfordert Linux/macOS-CI mit Python 3.11/3.14. Keine Modellläufe durchgeführt.

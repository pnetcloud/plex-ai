# Plex v0.5.5

Reguläre Veröffentlichung mit Korrekturen für Claude-Code-Delegation und einem klareren Einstieg.

- Claude-Rollen über `subagent_type` auswählen; Aufgabenlabels in `description` und im Auftrag führen. `name` entfällt, damit ein Label nicht versehentlich einen Agent-Teams-Teammate startet.
- Das native Werkzeug `Agent` für `delegation = false` sperren, auch für dev und QA im pnet-Team. BMad behält bedingte verschachtelte Delegation.
- Native Claude-Validierung, isolierte Plugininstallation und Konfigurationsprüfungen beider Teams ohne Modellaufrufe ergänzen.
- READMEs vereinfachen, abstrakte Claude-Chatbeispiele ergänzen und Team- sowie gemeinsame Pluginentfernung in vier Sprachen getrennt erklären.
- Diese und künftige Veröffentlichungen erscheinen ohne GitHub-Prerelease-Kennzeichnung oder Preview-Titel. Die Version bleibt 0.x; Schnittstellen können sich vor 1.0 ändern.

## Aktualisieren

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Plugin und verwaltete Rollen im Setup aktualisieren, danach eine neue Clientsitzung öffnen. Laufende Sitzungen werden nicht umgeschrieben.

## Validierung

139 lokale Tests bestanden, einschließlich Manifestvalidierung mit Claude Code 2.1.306, Plugininstallation in isolierter Konfiguration und pnet/BMad apply/check. Die Veröffentlichung erfordert Linux/macOS-CI mit Python 3.11/3.14. Keine neuen Modellaufgaben: geprüft wurden Installation und Konfiguration, nicht Live-Delegation, Modellverfügbarkeit oder Qualität.

# Plex v0.3.0 — Preview

Eine Quelle pro Agent, explizite BMad-Workflow-Auswahl und konfigurierbare Interaktion.

- Jedes Team besitzt eine Markdown-Quelle pro Agent. Setup erzeugt Codex-, Claude-Code-
  und Antigravity-Formate mit den bisherigen Werkzeug- und Zugriffseinstellungen.
  `pnet` und `bmad` bleiben unabhängige Teams.
- Der BMad-Katalog beschreibt 19 Operationen für sieben Rollen, einschließlich
  interner PO-Codes. Der Koordinator wählt aus dem geprüften Snapshot; der Subagent
  lädt nur den gewählten Workflow aus dem installierten BMad.
- Modi: `interactive`, `balanced` (Standard) und `auto`. Einstellung über `interaction`
  im Preset oder `--interaction auto` beim Setup. Eine ausdrückliche Nutzerwahl für
  einen Auftrag ändert die gespeicherte Konfiguration nicht.
- Subagenten melden Fragen an den Koordinator. Auto gibt Teilergebnisse und Blocker
  zurück, statt zu warten; unabhängige erlaubte Arbeit kann fortgesetzt werden.
  Native BMad-Headless-Verträge gelten, soweit unterstützt. Erforderliche Reviews,
  Prüfungen und Nutzerfreigaben bleiben bestehen.

## Installation und Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Für Updates `plex update` verwenden. Gewählte Client-Installationen aktualisieren
und den Client neu öffnen, damit Skills, Koordinatoranweisungen und Snapshots neu
geladen werden. Bestehende Receipts bleiben unterstützt. Ohne gespeicherte Wahl
verwendet die aktualisierte Konfiguration `balanced`.

## Prüfung und Grenzen

104 lokale Tests bestanden. Die Veröffentlichung erfordert Linux/macOS-CI mit
Python 3.11 und 3.14; native Client-Tests werden ohne verfügbares CLI übersprungen.
Keine neuen Modell-Benchmarks oder Live-Prüfungen der Interaktionsmodi durchgeführt.
Auto ist eine Anweisungsrichtlinie, keine Garantie unbeaufsichtigter Fertigstellung.
Offene Pflicht-Checkpoints bleiben Blocker. Auto erlaubt weder Analystenforschung
noch Veröffentlichung, destruktive Aktionen oder eine Erweiterung des Auftrags.

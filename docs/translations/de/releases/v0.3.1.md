# Plex v0.3.1 — Preview

Behebt den Setup-Abbruch bei vorhandenem `~/.local/bin/plex`.

- Normales Setup behält Befehle aus anderen Checkouts, fremde Dateien und defekte
  Links und setzt die Projekt- oder Benutzereinrichtung fort.
- Ein Hinweis zeigt den erhaltenen Befehl und den Einstiegspunkt des aktuellen
  Checkouts. Vorhandene Befehle werden nicht überschrieben.
- Explizites `--install-command` behält seinen Konfliktschutz. Verknüpfungen dieses
  Checkouts bleiben wiederverwendbar und aktualisierbar.

## Installation und Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Im Zielprojekt erneut ausführen. Ein erhaltener Link verweist weiterhin auf den
bisherigen Checkout; für die neue Kopie den angezeigten Einstiegspunkt verwenden.

105 lokale Tests bestanden, darunter fremde Checkout-Links, Dateien und defekte
Links. Veröffentlichung erfordert Linux/macOS-CI mit Python 3.11/3.14.
Keine Modellaufrufe oder neuen Benchmarks durchgeführt.

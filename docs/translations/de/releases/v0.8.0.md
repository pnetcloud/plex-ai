# Plex AI v0.8.0

Goal-Tokenbudgets sind jetzt optional; standardmäßig setzt Plex kein Tokenlimit.

- `.plex/preset.toml` unterstützt getrennte Einstellungen für
  `coordinator_token_budget` und `subagent_token_budget`.
- Fehlt eine Einstellung oder steht sie auf `0`, übermittelt Plex kein natives
  Tokenlimit. Ein positiver Wert fordert ein Limit für die jeweilige Rolle an.
- Goal-Aufträge benötigen kein Tokenbudget mehr, wenn der wirksame Wert nicht
  gesetzt ist. Explizite positive Budgets bleiben verfügbar.
- Alle nativen Plugin-Manifeste werden auf v0.8.0 aktualisiert.

Limits des Clients oder Anbieters bleiben bestehen; eine unbegrenzte Laufzeit der
Sitzung wird dadurch nicht garantiert.

## Aktualisierung

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Teamkonfiguration aktualisieren und eine neue Clientsitzung öffnen, damit Plugin
und Anweisungen geladen werden.

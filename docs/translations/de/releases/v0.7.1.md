# Plex AI v0.7.1

Projektstatus und Voraussetzungen für den Schnellstart sind jetzt klar angegeben.

- Plex ist als aktiv weiterentwickeltes Projekt zur Erprobung ausgewiesen; Unterstützung und Prüfungsumfang hängen vom Client ab.
- Alle README-Sprachen nennen Git, curl, die Client-CLI und uv oder Python 3.11+ als Voraussetzungen.
- Die Version aller nativen Plugin-Manifeste wurde auf v0.7.1 aktualisiert.

## Aktualisierung

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Teamkonfiguration aktualisieren und eine neue Client-Sitzung öffnen, damit Plugin und Anweisungen neu geladen werden.

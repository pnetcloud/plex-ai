# Совместимость клиентов

[English](../../host-compatibility.md) · [Русский](host-compatibility.md) · [Deutsch](../de/host-compatibility.md) · [简体中文](../zh-CN/host-compatibility.md)

Клиент исполняет агентов, поставщик предоставляет модели. Профиль поставщика не добавляет адаптер клиента.

| Клиент | Интеграция Plex | Проверки |
|---|---|---|
| OpenAI Codex | TOML-роли, плагин, области и инструкции | Изолированная установка/конфигурация и живые задачи |
| Anthropic Claude Code | Markdown-роли и путь установки плагина | Рендеринг/конфигурация; живые нативные прогоны не подтверждены |
| Google Antigravity | Markdown-роли и пакет плагина | Установка/конфигурация и отдельные живые испытания моделей |

Покрытие ограничено проверенными версиями и настройками: см. [тестирование](testing.md).
Gemini CLI — отдельный неподдерживаемый клиент. Новые адаптеры вне текущего охвата.

## Модели и разрешения

Codex получает `model`, `model_reasoning_effort`; Claude Code и Antigravity — `model`,
`effort`. Доступность зависит от реального клиента и модели. Рендеринг Antigravity
принимает `inherit`, `flash_lite`, `flash`, `pro`. Явный ID семейства в профиле не
доказывает поддержку исполнения: неподдерживаемая маршрутизация вызывает сообщение,
а не скрытую подмену. `inherit` наследует модель родителя и не выбирает Sonnet/Opus
независимо для каждого дочернего агента.

Нативные разрешения и лимиты имеют силу. Название роли, профиль и успешный рендеринг
не доказывают изоляцию инструментов, параллелизм или выбор модели. Plex не включает
другого клиента и не ослабляет глобальные разрешения ради работы адаптера.

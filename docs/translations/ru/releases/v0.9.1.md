# Plex AI v0.9.1

Hotfix документации: понятнее описаны профили моделей и оркестрация агентов.

- Добавлено сравнение моделей разработки и ревью в Basic, Plus, Pro и Pro+ для Codex, Claude Code и Antigravity.
- На английском, русском, немецком и китайском пояснены роли координатора и специалистов, режимы взаимодействия и особенности профилей BMad.
- Добавлено требование использовать скилл релизов для сопровождающих проекта.

Поведение и конфигурация не изменены; миграция проектов не требуется.

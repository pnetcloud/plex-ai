# Plex AI v0.19.3

Обе команды Plex теперь используют **GPT-6.2 Sol** (`gpt-6.2-sol`) и **GPT-6.2 Astra** (`gpt-6.2-astra`) в тех OpenAI-профилях, где раньше были выбраны Sol и Astra.

- Обновлены модели ролей `pnet` и `bmad`, включая рекомендации координатору Sol для Ultra и Ultra+.
- Распределение ролей и уровни рассуждения сохранены. Настройки Luna, Terra, Claude Code и Antigravity не меняются.
- Главные README обновлены на английском, русском, немецком и китайском. Исторические результаты сохраняют версии моделей, на которых проводились тесты.

Запустите `plex update`, сохранив команду и профиль, чтобы применить новые значения по умолчанию. Явные переопределения проекта сохраняют приоритет. Откройте новую сессию клиента для загрузки ролей. Рекомендация основному чату остаётся рекомендацией: модель выбирается в клиенте.

Проверка: полный переносимый набор тестов исходников, формирование конфигураций, упаковка, документация и синтаксис shell прошли проверки. Текущий каталог Codex содержит обе целевые модели и используемые уровни рассуждения. Живое сравнение моделей и измерение качества или скорости не проводились. Миграция формата конфигурации не требуется.

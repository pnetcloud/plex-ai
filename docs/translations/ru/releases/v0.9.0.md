# Plex AI v0.9.0

Plex больше не управляет бюджетами токенов.

- Удалены настройки бюджета, проверки заданий и инструкции о бюджетах для менеджеров и разработчиков.
- Refresh удаляет устаревшие поля, сохраняя команду, профиль, interaction, параллельность и индивидуальные настройки моделей.
- Сохраняются критерии приёмки, реальные блокеры и ограничения клиента. Лимит параллельных заданий не изменён.

```sh
plex update
```

Обновите конфигурацию проекта и откройте новую сессию. Старые чаты могут сохранять прежние инструкции; уже созданные native Goal не изменяются.

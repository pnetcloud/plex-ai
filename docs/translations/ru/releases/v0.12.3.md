# Plex AI v0.12.3

Рекомендации координатору теперь следуют одной обновлённой лестнице в командах `pnet` и BMad у всех четырёх провайдеров.

Для Plus рекомендуется high, Pro — xhigh, Pro+ — max, Ultra — low. Basic и Ultra+ не изменились. OpenAI использует Luna до Pro+ включительно и Sol в Ultra/Ultra+; Claude Code — Haiku, затем Sonnet. Native Google использует Flash до Pro+ включительно и наследует модель основного чата в Ultra. Claude в Antigravity сохраняет замены на Sonnet и точные запрошенные ID моделей.

Модели и reasoning субагентов, ID профилей и режимы взаимодействия не изменились. Это только рекомендации для основного чата: установщик не переключает его модель. Обновите Plex для просмотра новых рекомендаций и выберите модель в клиенте. Конфигурационные проверки и CI не доказывают фактическую маршрутизацию, одинаковое качество или экономию.

# Plex AI v0.18.1

Codex Pro теперь использует GPT-6.1 Terra для разработки в командах `pnet` и `bmad`, сохраняя прежний уровень рассуждения `max`.

- Рекомендация координатору: Terra / `medium` для Pro и Terra / `high` для Pro+.
- Разработчик Pro+ остаётся на Sol / `medium`; настройки остальных ролей и провайдеров сохранены.
- Обновлён вывод рекомендаций; документация профилей согласована на четырёх языках.

Запустите `plex update`, сохранив команду и профиль, чтобы применить новые значения по умолчанию. Пользовательские переопределения проекта сохраняют приоритет. Модель координатора выберите в основном чате: Plex не переключает модель работающего чата. Откройте новую сессию клиента для загрузки обновлённых ролей.

Проверка: пройдены проверки конфигурации, вывода CLI, документации и полный локальный набор тестов. Они не подтверждают реальную маршрутизацию, качество или скорость Terra в этих ролях. Миграция формата не требуется.

# Plex AI v0.17.0

Задания и ответы агентов под управлением Plex теперь используют читаемый Markdown с фиксированными заголовками, полями и списками. Обе команды используют общие шаблоны и валидатор.

- Сохраняются идентификатор задания, ревизия, роль, готовность, способ выполнения и от одного до пяти проверяемых критериев приёмки.
- Прогресс, запросы решения, блокировки и завершённые ответы проверяются относительно текущего задания, включая доказательства по критериям. Некорректные списки, неизвестные разделы контракта и повторяющиеся поля отклоняются.
- Прежние JSON-контракты остаются читаемыми, включая проверки задания и ответа в разных форматах. Текущую работу не нужно перезапускать, исторические файлы — переписывать.
- Маршруты координации и форматы возврата внутри workflow не меняются. Служебная оболочка вызовов и её отображение зависят от клиента; диагностика валидатора остаётся JSON.

Выполните `plex update` и примените конфигурацию для обновления инструкций ролей. Откройте новую сессию клиента, чтобы загрузить обновлённые инструкции. Исторические контракты автоматически не переписываются.

Проверено: локально прошли 250 тестов, включая Markdown-шаблоны, все статусы ответа, некорректные данные, многострочный текст и Unicode, совместимость с JSON, отсутствие записи при проверке CLI и экспорт пакетов для трёх клиентов. Поведение агентов и отображение в живых чатах не оценивались.

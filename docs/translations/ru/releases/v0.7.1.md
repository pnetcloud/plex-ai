# Plex AI v0.7.1

Уточнены статус проекта и требования для быстрого старта.

- Указано, что Plex активно развивается и доступен для оценки; поддержка и объём проверок зависят от клиента.
- Во все языковые версии README добавлены требования: Git, curl, CLI клиента и uv или Python 3.11+.
- Версии нативных плагинов обновлены до v0.7.1.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Обновите настройку команды и откройте новую сессию клиента, чтобы загрузить обновлённый плагин и инструкции.

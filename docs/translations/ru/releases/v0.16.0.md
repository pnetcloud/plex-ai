# Plex AI v0.16.0

Plex передаёт Dev/DevOps обычные технические шаги внутри принятого задания и делает память координатора читаемой в Markdown. Setup автоматически переносит существующие файлы памяти при применении конфигурации.

## Координация

- Существенные изменения области работы, приёмки, общих инвариантов или полномочий возвращаются владельцу решения. Обычные технические шаги выполняет назначенный исполнитель без нового круга PM.
- Независимая разрешённая разработка продолжается во время ожидания замеров, review или доставки. Следующее действие привязано к результату пользователя.
- Некорректный кандидат памяти блокирует его сохранение, а не уже принятое задание. Последнее корректное состояние сохраняется; память исправляется без повторной оценки задачи.
- Применимые изменения инструкций передаются повторно используемым исполнителям; обновление файлов само по себе не заменяет начальные инструкции работающего агента.

## Память и миграция

- Новая память использует проверяемый Markdown. Вместимость — 32 КиБ UTF-8 и до 16 текущих решений; точные имена исполнителей помещаются целиком. Предел хранения не ограничивает контекст модели или выполнение задачи.
- Setup переносит корректные канонические JSON-файлы в выбранной установке, проверяет Markdown, сохраняет резервные копии и удаляет старые файлы из рабочего каталога. Отдельного подтверждения нет.
- Миграция использует штатную транзакцию backup/rollback, сохраняет конкурентные изменения и приватность Markdown. Рабочая память не становится конфигурацией под управлением установщика.
- Конфликтные или некорректные файлы сохраняются с предупреждением. `plex status` показывает наблюдаемый формат памяти. Проверка старого пути может прочитать Markdown той же сессии и вернуть `canonical_path`.

Выполните `plex update` и примените конфигурацию. Одна загрузка исходников не переносит память проектов. Для загрузки обновлённых инструкций ролей откройте новую сессию клиента; действующие сессии могут сохранять прежние инструкции.

Проверено: 236 тестов, shell-проверки и чистая Docker-установка для Codex, Claude и Antigravity в проектной и пользовательской областях. Проверки миграции покрывают сохранность данных, повторные обновления, старые пути, конфликты, конкурентную запись и rollback. Они не доказывают улучшение поведения моделей в живых сессиях.

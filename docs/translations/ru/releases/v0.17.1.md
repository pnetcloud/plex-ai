# Plex AI v0.17.1

`plex update` теперь показывает текущую версию исходников и выбранную новую версию до загрузки, например `Plex update: v0.17.0 → v0.17.1`.

- Preview показывает тот же переход версий без изменения файлов.
- При первой установке выводится `not installed`; если текущую версию прочитать нельзя, выводится `unknown`, не блокируя допустимое обновление.
- При обновлении на ту же версию обе версии показаны явно. Выбор релиза, защита локальных изменений и поведение установщика не меняются.

Миграция не требуется. Выполните `plex update` для установки патча. Новый вывод появится после установки этого патча; при первом обновлении прежний установщик сохранит старый вывод.

Проверено: локально прошли 252 теста, включая выбор релиза, вывод до fetch, preview, первую установку, повтор той же версии, отсутствующие/некорректные метаданные и оформление CLI. Удалённые установки и поведение живых чатов не оценивались.

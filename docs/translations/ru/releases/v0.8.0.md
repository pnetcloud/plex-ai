# Plex AI v0.8.0

Лимиты токенов для Goal теперь необязательны: по умолчанию Plex их не задаёт.

- В `.plex/preset.toml` доступны отдельные параметры `coordinator_token_budget`
  и `subagent_token_budget`.
- Если параметр отсутствует или равен `0`, Plex не передаёт нативный лимит.
  Положительное значение запрашивает лимит для соответствующей роли.
- Для Goal больше не требуется указывать лимит, если эффективное значение не задано.
  Явные положительные лимиты по-прежнему поддерживаются.
- Версии всех нативных манифестов плагинов обновлены до v0.8.0.

Ограничения клиента или провайдера сохраняются; это не гарантирует бесконечную работу сессии.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Обновите конфигурацию команды и откройте новую сессию клиента, чтобы загрузить изменения.

# Plex v0.5.3 — Preview

Понятнее план установки и рекомендации координатора по профилям.

- Короткие пояснения в выборе профиля; фактические модели субагентов — в итоговом плане.
- Root coordinator (основной чат) показан отдельно от устанавливаемых субагентов.
- Рекомендации Codex хранятся в профилях обеих команд:
  Basic Luna/high, Plus Sol/low, Pro Sol/medium, Pro+ Sol/high.
- Модель основного чата выбирает пользователь. Для `inherit` конкретной рекомендации нет.
- Исправлены отступы между подписями и значениями CLI, включая пути скилов проекта.
- Обязанности координатора и выбор моделей описаны на четырёх языках.

## Установка или обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash -s -- --dev --client codex
```

## Проверки

Пройдены 138 локальных тестов. В терминале проверены выбор клавишами и отмена;
вывод плана проверен при ширине 40 и 80 столбцов. Публикация требует CI Linux/macOS
с Python 3.11/3.14. Нативные проверки пропускаются без CLI клиента. Модельные вызовы
и новые бенчмарки эффективности не запускались. Обновите конфигурацию установщиком
для обновления снимка. Это предварительный релиз.

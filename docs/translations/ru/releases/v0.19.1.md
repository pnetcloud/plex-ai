# Plex AI v0.19.1

Смена профиля Codex больше не блокируется только из-за удаления комментариев маршрутизации Plex при сохранении необходимых настроек.

- Перед принятием конфигурации без комментариев проверяются оба значения маршрутизации и их типы.
- Совпадающие значения сохраняются, а Plex прекращает считать их управляемыми: последующая деинсталляция их не удаляет.
- Отсутствующие и конфликтующие настройки, изменённые блоки с маркерами, повреждённые маркеры, симлинки и изменения после preview остаются защищены. Перекрытие файла инструкций — отдельный конфликт, требующий проверки.
- В главных README на английском, русском, немецком и китайском явно указана рекомендация координатору GPT-6.1 Terra для Pro/Pro+.

Запустите `plex update`, выберите Reconfigure и нужный профиль. Переопределения и посторонние настройки клиента сохраняются. Старые JSON-метаданные мигрируют существующим механизмом с проверенными резервными копиями; новый формат конфигурации не добавляется.

Проверка: регрессионные тесты охватывают статус без записи, смену профиля, повторное обновление, деинсталляцию и отказ при реальном изменении маршрутизации. Полный локальный набор тестов и проверки shell прошли. Проверка конфигурации не доказывает загрузку новых ролей действующим чатом или реальное выполнение маршрутизации моделей.

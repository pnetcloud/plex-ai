# Plex AI v0.16.2

Plex хранит `applied.toml`, `resolved.toml` и `skill-aliases.toml` рядом с `preset.toml` в `.plex/`, чтобы сгенерированную конфигурацию было легче читать.

- Setup автоматически переносит три прежних JSON-файла при применении конфигурации. Настройки, overrides и записи владения сохраняются; оригиналы уходят в проверенные резервные копии, при сбое выполняется rollback.
- Статус и preview читают прежние установки без изменений. Одинаковые копии объединяются; конфликтующие JSON/TOML сохраняются. Конкурентная запись и symlinks защищены.
- `plex status` показывает наблюдаемый формат конфигурации. Валидатор заданий принимает старые и новые snapshots; вывод CLI `--json` остаётся JSON.
- Память координатора явно определена как помощь продолжению работы. Координатор использует весь доступный контекст сессии, принятые требования и корректировки пользователя; отсутствие детали в checkpoint не отменяет её.

Тест миграции на macOS теперь сравнивает разрешённые пути. Тег v0.16.1 не привёл к публикации релиза из-за ошибки этого теста в CI.

Выполните `plex update` и примените конфигурацию для автоматической миграции. Сгенерированными файлами управляет установщик; постоянные настройки остаются в `preset.toml`. Новые сессии клиента загружают обновлённые инструкции ролей; действующие могут сохранять прежние инструкции.

Проверено: 244 теста и чистая Docker-установка Codex, Claude и Antigravity в проектной и пользовательской областях. Проверки миграции покрывают сохранение данных, повторные обновления, чтение и удаление прежних установок, конфликты, конкурентную запись и rollback. Поведение моделей в живых сессиях не оценивалось.

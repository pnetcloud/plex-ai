# Plex v0.3.0 — Preview

Один исходник агента, явный выбор workflow BMad и настраиваемое взаимодействие.

- У каждой команды один Markdown-исходник на агента. Установщик генерирует форматы
  Codex, Claude Code и Antigravity с прежними настройками инструментов и доступа.
  Команды `pnet` и `bmad` остаются независимыми.
- Каталог BMad описывает 19 операций семи ролей, включая внутренние коды PO.
  Координатор выбирает workflow из проверенного snapshot; субагент загружает только
  выбранный workflow установленного BMad.
- Режимы: `interactive`, `balanced` (по умолчанию), `auto`. Настройка — `interaction`
  в preset или `--interaction auto` у установщика. Пользователь может явно выбрать
  режим на одну задачу без изменения сохранённых настроек.
- Субагенты возвращают вопросы координатору. Auto возвращает частичный результат
  и блокеры без ожидания, позволяя продолжить независимую разрешённую работу.
  Штатный headless BMad используется там, где он поддерживается; обязательные
  ревью, проверки и разрешения пользователя сохраняются.

## Установка и обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Для обновления используйте `plex update`. Обновите выбранные клиентские установки
и перезапустите клиент, чтобы загрузить новые skills, инструкции и snapshots.
Существующие receipts поддерживаются. Если режим не был сохранён, после обновления
используется `balanced`.

## Проверки и ограничения

Локально прошли 104 теста. Публикация требует успешного CI Linux/macOS на Python
3.11 и 3.14; проверки нативного клиента пропускаются, если его CLI отсутствует.
Новых модельных бенчмарков и живых проверок режимов взаимодействия не проводилось.
Auto — политика инструкций, а не гарантия завершения любого workflow без участия
человека. Обязательные нерешённые checkpoints остаются блокерами; auto не разрешает
исследование аналитика, публикацию, разрушительные действия или расширение задачи.

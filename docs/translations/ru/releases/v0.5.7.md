# Plex v0.5.7

Единая структура координаторов и руководство для авторов.

- Привести координаторов pnet/BMad к блокам субагентов: активация, порядок работы, фокус, проверки, результат и границы.
- Сохранить выбор нативных ролей, доказательства активации, gates workflow, владение файлами, лимиты и восстановление.
- Добавить CONTRIBUTING.md со ссылками на правила разработки. Обновить стандарт ролей на четырёх языках.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Обновите плагин через установщик, переоткройте клиент и вызовите Plex.

## Проверки

Прошли 139 локальных тестов, включая экспорт пакетов и изолированные нативные проверки клиентов. Публикация требует CI Linux/macOS на Python 3.11/3.14. Живой прогон с моделями не выполнялся; более ясные инструкции не доказывают улучшение их соблюдения.

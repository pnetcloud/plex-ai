# Plex AI v0.6.0

Надёжная передача заданий в auto и нативный выбор ролей Codex.

## Изменения

- Незакоммиченные изменения сами по себе больше не требуют согласования. Чужие файлы и существующие фрагменты внутри назначенных файлов сохраняются; разрешение передаётся BMad. Реальные конфликты scope, ограничения production и обязательные review остаются.
- Установщик Codex управляет `hide_spawn_agent_metadata = false` и `tool_namespace = "agents"`: резервирование, проверка конфликтов, обновление, откат и удаление. Личные значения не затираются.
- Preflight различает отсутствие инструмента, скрытый выбор роли, отклонённую роль и принятый вызов. Handoff с новым контекстом включает режим, владение файлами и существующие разрешения.
- Оформление Plex AI by pNet: утверждённое превью Triad, живые бейджи, схема и навигация документации на четырёх языках.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Выберите **Update only**, проверьте доверие Codex к проекту и откройте **новую сессию**. Старая сессия автоматически не получает новые параметры выбора ролей. Старые установщики не читают новый routing receipt; используйте v0.6.0 или новее.

## Проверка

167 локальных тестов: 166 прошли, один пропущен без Claude CLI. Реальные вызовы Codex CLI подтвердили `plex-dev` на Luna / max и `plex-reviewer` на Sol / medium. Координатор Luna / max завершил BMad Build с review на грязном дереве, сохранив чужой файл и существующую правку внутри рабочего файла. Реальный недостаток разрешений на workflow-артефакты вернул блокер без вопроса; после явного разрешения продолжилось то же задание.

Это отдельные нативные прогоны, а не гарантия полной автономности или проверка каждого Desktop-клиента. Production-приложение при тестировании не менялось.

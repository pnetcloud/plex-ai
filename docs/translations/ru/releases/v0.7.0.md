# Plex AI v0.7.0

Постановка заданий через PM/PO и ограниченная работа до проверенного результата.

- PM/PO выбирает обычное выполнение, предварительный план или работу до цели с одним–пятью наблюдаемыми критериями. Root организует поручения и собирает доказательства.
- Короткий JSON-контракт и валидатор без записи проверяют роль, входы, границы, готовность и настройки исполнения по проверенному snapshot команды. Существующие issue/spec/story остаются каноническими.
- Native Plan/Goal необязательны: без них сохраняется обычное планирование или ограниченная работа по критериям. Для native Goal запрашивается 50 000 токенов без автоматического продления; отсутствие учёта явно обозначается.
- Добавлен установленный `bmad-build-auto` для одной автономной итерации. Сохраняются renderer, обязательные субагенты, review и протокол завершения; готовая спецификация используется без второго конвейера планирования.
- Агенты переиспользуются и получают изменившиеся данные. Незавершённые задания считаются отдельно от нативных слотов; пути и ревизии артефактов передаются точно, без подмены похожими именами.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Обновите настройку и откройте новую сессию клиента для загрузки инструкций и каталога workflow. Состав команд, модели и интерфейсы настройки установщика не менялись.

Проверка: 174 локальных теста — 173 прошли, один пропущен без Claude CLI; шесть offline Docker-циклов установки для всех клиентов и обоих scope. Нативный pnet-прогон и итерация установленного BMad Build Auto завершены, включая четыре review-исполнителя workflow. Live-smoke выполнялись без sandbox из-за ошибки инициализации `bwrap` на стенде; активация native Goal, обеспечение бюджета и автоматическое продолжение не проверялись.

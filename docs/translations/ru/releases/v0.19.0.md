# Plex AI v0.19.0

Теперь перед реализацией кода по новым или существенно изменённым исполняемым требованиям BMad требуется семантическая проверка. Она использует поддерживаемую операцию установленной версии и адаптер проекта и фиксирует точный набор требований, релевантные сценарии, конечные критерии приёмки, замечания и их статус. До этой границы Build может исследовать проблему, проводить диагностику, планировать и готовить рабочую spec. Если spec требует проверки, приостанавливается только реализация кода; тот же Dev продолжает работу с безопасной точки после устранения существенных пробелов. Уже принятую работу не перезапускают задним числом.

- До принятия реализации требуется независимое ревью точного кандидата и требований. Завершённое и подтверждённое независимое ревью внутри Build засчитывается один раз; иначе кандидат направляется отдельному reviewer.
- Доказательства проверки и ревью повторно используются, только пока не изменились все их входные данные. Более позднее явное решение человека сохраняет приоритет.
- Обновлены инструкции обеих команд и переводы контрактов ролей. Схемы заданий и сохранённые настройки не меняются.

Запустите `plex update`, сохранив текущие команду и профиль, чтобы обновить роли. Откройте новую сессию клиента для их загрузки. Миграция формата не требуется.

Проверка: полный локальный набор тестов, синтаксис shell и проверки документации/пакетов пройдены на точном коммите релиза. Эти проверки не подтверждают исполнение живого BMad workflow или поведение приложения.

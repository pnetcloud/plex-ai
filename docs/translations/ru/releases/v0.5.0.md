# Plex v0.5.0 — Preview

Обновление существующей установки без повторного опроса и тестирование рабочей копии через Codex.

- Установленная команда предлагает **Update only** или **Reconfigure**. Обновление
  сохраняет команду, профиль, режим взаимодействия, параллельность, переопределения
  и выбор блока инструкций каждого клиента. Явные параметры CLI продолжают действовать;
  для нескольких клиентов выбранное действие переиспользуется.
- В меню появился выбор **interactive / balanced / auto**. Поле `interaction`
  записывается в каждый применённый preset; старые получают недостающее значение.
- Проектный `--dev` для Codex подключает обе полные папки скиллов Plex ссылками на
  рабочую копию и отключает общий плагин только в этом доверенном проекте. Блок
  инструкций требует проектные скиллы Plex; references, проверка, координатор
  и ресурсы команды берутся из того же источника. BMad остаётся отдельной зависимостью.
- `--no-dev` и удаление убирают только принадлежащие Plex ссылки и отключение плагина.
  Status показывает dev-источник. Скиллы доступны через живые ссылки; после изменений
  ролей, профилей или каталога нужно обновить установку и открыть новую сессию.
- Новые маркеры — `plex:managed:start/end`. Неизменённые управляемые старые блоки
  обновляются с сохранением окружающего текста. Старые идентификаторы профилей
  сохраняются при обновлении. Конфликты файлов и неизвестные поля конфигурации или
  записи установки останавливают операцию вместо сброса настроек.
- Установка и все параметры CLI вынесены в `readme/`: английская, русская, немецкая
  и китайская версии связаны с корневыми README.

## Установка или обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Для рабочей копии запускайте её установщик напрямую:

```sh
./setup.sh --dev --client codex --project /path/to/test-project
```

Выберите область project, сохраняйте рабочую копию и откройте клиент заново.
Dev пока поддерживает только Codex; облачные плагины и другие одноимённые отдельные
скиллы не отключаются. Для проектной конфигурации требуется доверие Codex к проекту.

## Проверки и ограничения

Пройдены 127 локальных тестов, включая изолированные проверки Codex: плагин отключён
в тестовом проекте, включён в соседнем и снова обнаруживается после выхода из dev.
Покрыты сохранение настроек при обновлении, старые presets/маркеры, выбор инструкций
для нескольких клиентов, конфликты и откат. Публикация требует CI Linux/macOS,
Python 3.11/3.14; нативные проверки пропускаются без соответствующего CLI.
Вызовов моделей и новых измерений качества/стоимости не было. Изменения менеджера
плагинов отделены от отката файлов ролей. Это предварительный релиз.

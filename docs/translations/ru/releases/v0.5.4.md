# Plex v0.5.4 — Preview

Хотфикс координации: явный выбор роли и понятные имена поручений.

- Выбор нативной роли `plex-<role>` вынесен в начало скилла и обоих координаторов.
- Имена поручений — `plex_<role>_<short_task>`, метки сообщений — `[plex:<role>:<short_task>]`. При повторном использовании потока указывается актуальная задача; системный nickname может остаться прежним.
- Недоступные роли и конфликты маршрутизации сообщаются явно, без молчаливой замены универсальным агентом.
- Инструкции читаются отдельно; обрезанные части необходимо дочитать до делегирования.
- Подробные правила BMad вынесены в отдельный контракт с сохранением проверок workflow и проектных адаптеров.
- При продолжении сохраняется короткий checkpoint с путями, владельцем изменений, доказательствами и следующей проверкой.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Запустите установщик для обновления общего пакета и управляемых инструкций проекта, затем откройте новую сессию клиента и вызовите Plex. Уже работающие потоки не переписываются.

## Проверки

Пройдены 138 локальных тестов, включая упаковку отдельного контракта для трёх клиентов. Проверены относительные ссылки и сохранность перенесённых правил BMad. Публикация требует CI Linux/macOS с Python 3.11/3.14. Новый модельный запуск делегирования не проводился; проверки пакета не доказывают живую маршрутизацию. Это предварительный релиз.

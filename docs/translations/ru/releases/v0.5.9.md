# Plex v0.5.9

Выбор только активной команды и очистка старых агентов по согласию.

- Поручения Plex используют только точные нативные роли проверенной активной команды. Другие, встроенные и устаревшие роли исключены, включая неактивные имена с префиксом plex-. Исполнители внутри workflow сохраняют контракт workflow.
- Установщик Codex показывает других агентов только при обнаружении. По умолчанию — сохранить; перенос подходящих файлов в backup требует явного выбора или `--archive-other-agents`.
- Очистка ограничена выбранной областью установки. Backup сохраняет содержимое файлов; проверка хешей preview и откат защищают от изменений файлов и ошибок настройки ролей.
- Символические ссылки, явные регистрации `config.toml` и управляемые роли сохраняются. Изменённые управляемые файлы остаются конфликтами.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Обновите настройку, чтобы применить новые инструкции и роли, затем откройте новую сессию. Одна загрузка пакета не меняет существующие установки.

## Validation

Пройден 161 локальный тест: сохранение по умолчанию, условный показ меню, отмена, dry run, проверка backup, конкурентные изменения, откат, разделение project/user и установка нескольких клиентов. Прогоны с моделями не выполнялись.

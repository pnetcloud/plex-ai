# Plex v0.5.2 — Preview

Короткий быстрый старт и структурированное руководство. Поведение установщика не изменено.

- В быстром старте — обычная установка и альтернатива `--dev` для Codex.
- Убрано создание демонстрационной папки; требования остались в руководстве.
- Длинное описание заменено таблицами задач и команд, отдельными разделами Dev/BMad,
  группами параметров и кратким решением проблем. Все параметры CLI сохранены.
- Описан запуск из рабочей копии, если после первой dev-установки нет команды `plex`.
- Синхронно обновлены английская, русская, немецкая и китайская версии.

## Установка или обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Dev-режим для Codex из папки проекта:

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash -s -- --dev --client codex
```

## Проверки

Пройдены 135 локальных тестов. Проверены ссылки документации, все 25 флагов установки
и передача аргументов dev-режима. Публикация требует CI Linux/macOS, Python 3.11/3.14;
нативные проверки пропускаются без CLI клиента. Дополнительную ручную установку или модельную
сессию для этого релиза документации не запускали. Это предварительный релиз.

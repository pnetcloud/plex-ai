# Plex v0.5.8

Порядок в документации и короткие имена скиллов Codex.

- В корне один английский README со ссылками на русский, немецкий и китайский обзоры в `docs/translations`.
- Инструкции установки перенесены в docs; оглавления переводов находятся рядом с README своего языка.
- Вызовы `$plex` и `$plex-setup` доступны через управляемые ссылки на общую рабочую копию, в проекте или профиле пользователя. В обычном режиме плагин включён; dev остаётся режимом проекта.
- Чужие скиллы и изменённые ссылки сохраняются; собственные ссылки учитываются при обновлении, проверке, удалении и откате.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Один раз обновите настройку для добавления коротких имён Codex и откройте новую сессию. Сохраняйте общую рабочую копию. Новая установка `roles-only` не добавляет ссылки. Claude Code сохраняет `/pnet-plex:plex`.

## Проверка

Пройдены 149 локальных тестов, включая обнаружение обоих коротких имён самим Codex в проекте и профиле пользователя. Проверки пакетов охватывают изолированную нативную установку клиентов. Публикация требует CI Linux/macOS на Python 3.11/3.14. Прогоны с моделями не выполнялись.

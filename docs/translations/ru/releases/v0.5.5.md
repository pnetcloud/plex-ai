# Plex v0.5.5

Обычный релиз с исправлениями делегирования Claude Code и более понятным быстрым стартом.

- Роли Claude выбираются через `subagent_type`, метки задач передаются в `description` и тексте задания. Параметр `name` не используется, чтобы случайно не запускать teammate Agent Teams.
- Для `delegation = false` запрещён нативный инструмент `Agent`, включая dev и QA команды pnet. BMad сохраняет условное вложенное делегирование.
- Добавлены нативная валидация Claude, изолированная установка плагина и проверки настройки обеих команд без вызовов модели.
- Упрощены README, добавлены абстрактные примеры чата Claude; удаление команды и общего плагина описано отдельно на четырёх языках.
- Этот и следующие релизы публикуются без отметки prerelease и слова Preview. Версия остаётся 0.x; интерфейсы могут развиваться до 1.0.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Обновите плагин и управляемые роли через установщик, затем откройте новую сессию клиента. Работающие сессии не переписываются.

## Проверки

Прошли 139 локальных тестов, включая валидацию манифеста Claude Code 2.1.306, установку плагина в изолированную конфигурацию и apply/check для pnet/BMad. Публикация требует CI Linux/macOS на Python 3.11/3.14. Новые задачи с моделями не запускались: проверены установка и конфигурация, а не живое делегирование, доступность моделей или качество.

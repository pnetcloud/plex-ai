# Plex v0.5.11

Стабильный macOS CI, делегирование и настройки установки.

- Закрепить macOS CI на поддерживаемом пуле `macos-15-intel` после срыва выделения ARM-runner до запуска тестов. Сохранены обе версии Python и все условия публикации.
- В финальном **Apply this plan?** при установке и обновлении по умолчанию выбрано Yes. No отменяет; удаление и архивирование других агентов сохраняют отдельное подтверждение.
- Инструкции координатора явно требуют нативных вызовов субагентов для содержательной работы, в том числе после продолжений и сжатия контекста. Мелкие механические действия и координация остаются локальными.
- Добавлены проверка локальных Markdown-ссылок и цикл установки в чистом Docker для трёх клиентов в project/user scope. Контейнер использует Python без uv и клиентских CLI, без сети и привилегий root.
- Публикация требует успешной матрицы Linux/macOS, Python 3.11/3.14, и Docker-проверки.

## Update

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Обновите настройку, откройте новую сессию клиента и вызовите Plex, чтобы загрузить новые инструкции координатора.

## Validation

Пройдены 162 локальных теста и шесть сценариев установки в чистом контейнере. Нативный Windows и поведение моделей не проверялись.

# Plex v0.5.1 — Preview

Более читаемый терминальный интерфейс установки и обслуживания.

- Общие заголовки, выровненные параметры и таблицы агентов/моделей; выделение жирным
  и цветом для команд, успешных действий, предупреждений и ошибок.
- Компактный план показывает путь к инструкциям без полного текста шаблона.
  В узком терминале параметры агентов располагаются друг под другом.
- В меню — чёткие названия и пояснение выбранного пункта без выделения всей строки.
  Справка группирует параметры по назначению и содержит примеры команд.
- Status и удаление показывают читаемые сводки. `--json` сохраняет чистый stdout
  для status, предпросмотра удаления, удаления и его отмены.
- Перенаправленный вывод, `NO_COLOR` и `TERM=dumb` остаются обычным текстом.
  Простые интерактивные меню используют номера. Загрузка исходников сообщает о ходе
  работы без необработанного вывода Git clone.
- Команды остаются пригодными для копирования. Если команды `plex` нет,
  подсказки после установки используют текущую точку входа.

## Установка или обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Попробуйте `plex --help`, `plex status` или предпросмотр из папки проекта:

```sh
plex --dry-run --client codex --project .
```

Для машиночитаемого плана удаления: `plex uninstall --dry-run --json`.

## Проверки и ограничения

Пройдены 135 локальных тестов. В настоящих терминалах шириной 80 и 40 колонок проверены
цвета и адаптация вывода. Интерактивный запуск выбрал Balanced, дошёл до подтверждения
и отменил установку без записи в проект. JSON и простой вывод покрыты отдельными тестами.
Публикация требует CI Linux/macOS с Python 3.11/3.14; нативные проверки пропускаются
без CLI клиента. Вызовов моделей и новых измерений качества/стоимости не было.
Это предварительный релиз.

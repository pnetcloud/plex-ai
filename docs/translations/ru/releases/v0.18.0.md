# Plex AI v0.18.0

Установщик Claude Code теперь управляет узким доступом к установленному пакету Plex и его проверяющим скриптам, чтобы установка из исходников и выполнение из кэша использовали один путь.

- Реальный путь берётся из нативного inventory; существующий кэш Claude явно обновляется. Roles-only refresh сохраняет записанный путь.
- Личные настройки и правила сохраняются. Изменение управляемого правила блокирует refresh; backup, rollback и удаление используют существующий механизм владения. Для BMad добавляется чтение скиллов, без общего разрешения выполнять runtime.
- BMad для Claude устанавливается с `--copy`, отдельно от общих копий Codex. Установка остальных клиентов не меняется.
- Проверенный путь пакета передаётся внутри Markdown Inputs. Markdown-контракты, совместимость с JSON и форматы workflow сохраняются; произвольный префикс перед контрактом не добавляется.

Выполните `plex update` с обычной установкой плагина, затем перезапустите Claude для загрузки плагина и ролей. Roles-only refresh не обновляет нативный кэш. Уже выполняемые задания не нужно перезапускать ради формата.

Проверено: локально прошли 268 тестов, включая обновление кэша CLI 2.1.310 и установку из checkout, конфигурацию обеих команд, сохранение личных правил, удаление, rollback, symlinks и конкурентные изменения. Это не подтверждает все сочетания моделей/профилей или загрузку действующей сессией.

Отдельная живая проверка Haiku в режиме `dontAsk` зафиксировала реальные вызовы Read и Bash для пакета в кэше и валидатора, без отказов доступа. Командный workflow и маршрутизация дочерних агентов в ней не проверялись.

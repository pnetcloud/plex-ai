# Plex AI v0.15.0

Теперь Plex продолжает многоэтапную работу с зафиксированной передачей результатов. PM/PO получает краткие правила выбора специалистов, а setup BMad сначала проверяет закреплённый каталог skills и только потом меняет пользовательские файлы.

## Координация

- Каждый переданный результат фиксируется в состоянии координатора, а у родительской задачи обновляется `next_action`. Блокировка следующего этапа не открывает завершённый снова; PM повторно оценивает задачу только при существенном изменении evidence или решения пользователя.
- Классифицируйте по масштабу изменения и нерешённому вопросу, а не по ярлыку «баг» или «функция»: готовые изменения в известных границах передавайте Dev; продуктовые и UX-вопросы — PM/PO и UX по необходимости; новые или изменённые возможности, затрагивающие границы подсистем, сервисов и хранилищ, общие интерфейсы, владение данными или инварианты, а также противоречивую или отсутствующую архитектуру — Architect в BMad. В pnet технический план выполняет PM; неизвестные причины направляются на диагностику.
- Завершайте диагностику, когда подтверждённая причина позволяет безопасно исправить код. Проверки идентичности и возможных эффектов в production обязательны для ACK, replay и изменения данных, но не блокируют изолированный фикс с безопасной остановкой неизвестных случаев. Если тестовый runner не запустил тесты, выполните одну адресную коррекцию окружения или отметьте проверку как заблокированную.

## Установка BMad

- Перед установкой skills проверьте каталог закреплённого официального исходника. Если обязательного skill нет, setup останавливается до записи файлов.
- Устанавливаются только отсутствующие skills; существующие корректные файлы сохраняются. Частичную установку можно безопасно повторить. Неполный существующий путь оставляется без изменений для проверки.
- Каталог workflows содержит только skills, доступные в закреплённом исходнике.

Чтобы загрузить обновлённые инструкции ролей, обновите конфигурацию проекта и откройте новую сессию клиента. Снимки конфигурации и уже открытые сессии автоматически не обновляются. Если закреплённый каталог нельзя проверить, установка останавливается до изменения пользовательских файлов skills.

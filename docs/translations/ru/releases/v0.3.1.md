# Plex v0.3.1 — Preview

Исправлена остановка установки при существующей команде `~/.local/bin/plex`.

- Обычная установка сохраняет команду из другой копии, чужой файл или битую ссылку
  и продолжает настройку проекта либо пользовательской области.
- Уведомление показывает сохранённую команду и путь запуска текущей копии.
  Существующая команда не перезаписывается.
- Явный `--install-command` сохраняет защиту от конфликта. Ярлыки этой же копии
  можно по-прежнему повторно использовать и обновлять.

## Установка и обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Повторите команду из нужного проекта. Сохранённый ярлык продолжает вести в прежнюю
копию; для запуска новой используйте путь, который покажет установщик.

Локально прошли 105 тестов, включая ярлык другой копии, чужой файл и битую ссылку.
Публикация требует CI Linux/macOS на Python 3.11/3.14. Запусков моделей и новых
бенчмарков не проводилось.

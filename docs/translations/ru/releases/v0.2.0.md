# Plex v0.2.0 — Предварительный релиз

Команды обслуживания и воспроизводимая установка для внешнего тестирования.

- `plex status` показывает версию, область, команду/профиль, роли, обнаружение плагина и конфликты; `--json` даёт машинный вывод.
- Установка и `plex update` выбирают опубликованные релизы, включая preview. `--release` закрепляет тег, `--development` явно выбирает `main`. Изменённые и чужие копии сохраняются.
- Переносимые тесты опубликованы. CI проверяет Linux/macOS с Python 3.11/3.14 и блокирует публикацию при ошибке; нативные проверки пропускаются без CLI клиента.
- `plex uninstall` показывает план и запрашивает подтверждение, проверяет хеши receipt, сохраняет чужие/изменённые файлы и общие блоки, создаёт backups. Прерывания и обработанные ошибки откатываются, когда возможно.

## Попробовать

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Запускайте из проекта. После удаления выбранной области остаются общие плагины, исходники, команда CLI, preset и backups. Проектные предпочтения сохраняют приоритет, область автоматически не переключается. После изменений откройте новую сессию клиента.

Это prerelease. Новые модельные тесты не запускались; нативный Claude Code и прежние ограничения исследования остаются непроверенными.

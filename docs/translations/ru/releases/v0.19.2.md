# Plex AI v0.19.2

Координатор Plex теперь проверяет продвижение к наблюдаемым результатам приёмки, не полагаясь только на повторяющиеся статусы.

- Если последовательные отчёты не дают новых доказательств по одному этапу, сверить указанный артефакт или проверку. Запросить недостающие сведения у того же исполнителя только при необходимости; при неизменных наблюдениях использовать уже полученный ответ.
- Продвигающаяся разработка продолжается без повторных запросов статуса, перезапуска Build и лишних управленческих циклов. Тесты компонентов остаются частичным доказательством, а не подтверждением готовой интеграции.
- Владелец, блокер и следующий шаг checkpoint сверяются с текущим принятым заданием. Завершённая работа, необходимые решения специалистов, человеческие согласования и проверки workflow сохраняются.
- Частота неизменных ожиданий снижается в пределах ограничений клиента. Таймер выполнения, бюджет токенов, смена модели и новая схема контрактов не добавляются.

Запустите `plex update`, сохранив команду и профиль. Для загрузки инструкций откройте новую сессию либо явно передайте изменения правил действующему координатору и переиспользуемым исполнителям. Обновление файлов само по себе не меняет начальные инструкции работающего агента. Не перезапускайте завершённую работу ради принятия патча.

Проверка: полный локальный набор тестов и проверки shell прошли, включая контракты, checkpoint, документацию и упаковку. Разбор сценариев охватывает устаревшую память, повторяющиеся статусы и действительно продвигающуюся работу. Это инструкции, а не детерминированный детектор циклов; улучшение реального поведения предстоит наблюдать.

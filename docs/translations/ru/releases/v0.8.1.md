# Plex AI v0.8.1

Роли Codex наследуют права основного чата.

- В TOML ролей не записываются `sandbox_mode` и `approval_policy`. Настраивайте
  права и MCP в родительской сессии.
- Инструкция «только чтение» остаётся поведенческим ограничением, а не отдельным
  sandbox. Ограничения инструментов Claude Code и Antigravity сохранены.
- Обновление удаляет старое поле sandbox из неизменённых управляемых ролей с
  резервным копированием. Локальные правки по-прежнему вызывают конфликт и не затираются.

## Обновление

```sh
curl -fsSL https://raw.githubusercontent.com/pnetcloud/plex-ai/main/install.sh | bash
```

Обновите конфигурацию команды и откройте новую сессию клиента для загрузки ролей.

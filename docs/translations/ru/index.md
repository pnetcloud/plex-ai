# Документация Plex

[English](../../README.md) · [Русский](index.md) · [Deutsch](../de/index.md) · [简体中文](../zh-CN/index.md)

Plex настраивает и координирует команды агентов в Codex, Claude Code и Antigravity.

## Начните здесь

1. [Установите Plex](installation.md) — требования, обычный и dev-режим.
2. [Выберите команду и профиль](configuration.md) — модели, взаимодействие и параллелизм.
3. [Вызовите Plex в чате](README.md) — координация и проверка результата.
